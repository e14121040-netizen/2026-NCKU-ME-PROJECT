# EV3 運輸機器人 — 組裝設計參考

## 底盤結構

### 驅動方式
- **差速驅動**：左右各 1 顆大馬達，後方 1 顆萬向輪/球輪
- 輪距 (Axle Track) ≈ 120mm（程式中 `AXLE_TRACK = 120`）
- 輪徑 (Wheel Diameter) = 56mm（EV3 大輪，程式中 `WHEEL_DIAMETER = 56`）

### 建議佈局

```
        前方（行進方向 →）
    ┌──────────────────────┐
    │                      │
    │     [S1 前下感測器]    │  ← 顏色感測器朝下
    │                      │
    │   ┌────────────┐    │
    │   │  輸送帶帶面  │    │  ← 頂部水平輸送帶 (Motor A)
    │   │  →→→→→→  │    │    零件往外側推落
    │   └────────────┘    │
    │        EV3           │
    │       Brick          │
    │                      │
    │  ◎左輪          右輪◎ │  ← Port D, C
    │                      │
    │     ● 萬向輪         │
    │                      │
    │   [觸碰感測器 S4]    │
    └──────────────────────┘
```

## 感測器安裝

### 單循跡與停止線感測器（S1）

- **位置**：底盤前方正中央，距地面 ≈ 5~10mm
- **朝向**：正下方朝地面
- **用途**：同時負責 PID 黑線左緣循跡，以及偵測黃色（放置區）/ 紅色（起點）停止線。
- **原理**：
  - 在黑線上 → 反射值低（低於 `LINE_THRESHOLD`，通常 < 20）
  - 在白底上 → 反射值高（通常 > 50）
  - `error = reflection - threshold`，正值右轉，負值左轉。
  - 同時在迴圈中呼叫 `color()` 方法偵測有無遇到黃線/紅線。

### 觸碰感測器（S4）

- **位置**：底盤後方或放置機構旁
- **用途**：啟動按鈕 + 偵測零件放置完成

## 輸送帶機構設計

### 需求
- 將取物機器人放置在頂部帶面上的零件，運送至外側推落入放置區平台（高度 100mm）

### 方案：水平輸送帶
```
側視圖：
                零件
     → → → → [■] → → 推落
    ┌═══════════════┐
    │  履帶帶面         │ ← LEGO 履帶組
    └═══════════════┘
    ◎驅動輪          ○惰輪
    (Motor A)
```
- Port A 中馬達驅動履帶驅動輪，帶面向外側移動
- 程式中 `CONVEYOR_SPEED = 300` deg/s、`CONVEYOR_RUN_TIME = 3000` ms
- 運轉時間需依實際帶長調整，確保所有零件都能推落

### 安裝要點
- 輸送帶安裝在底盤頂部，帶面與底盤平行
- 驅動輪靠內側（取物機器人放置端），惰輪靠外側（推落端）
- 推落端需對齊放置區平台位置
- 注意帶面張力，避免過鬆打滑或過緊增加馬達負擔

## 尺寸限制

- 機器人尺寸：**長 ≤ 400mm、寬 ≤ 300mm**（⚠ 寬度比取物機器人小！）
- EV3 底盤通常遠小於限制，但需注意感測器突出部分

## 組裝順序

1. 先組底盤 + 兩大馬達 + 萬向輪
2. 安裝 EV3 Brick
3. 安裝前下顏色感測器 (S1)，確認高度
4. 組裝頂部輸送帶機構（履帶 + 驅動輪 + 惰輪）+ 中馬達 (A)
5. 安裝觸碰感測器 (S4)
6. 連接所有線材
7. 部署程式，開始測試

## 常見問題

| 問題 | 解決方法 |
|------|----------|
| 循跡不穩、左右晃 | 調整 KP/KD、降低 BASE_SPEED |
| 顏色辨識失敗 | 確認感測器離地高度，周圍光線不要太強 |
| 輸送帶推不動零件 | 提高 CONVEYOR_SPEED、檢查帶面張力、減輕零件重量 |
| 零件推不完全 | 增加 CONVEYOR_RUN_TIME，確保運轉時間足夠 |
| 馬達方向反了 | 修改 `Direction.CLOCKWISE` / `COUNTERCLOCKWISE` |
| EV3 連不上電腦 | 確認 microSD 卡已安裝 Pybricks、USB 線正常 |
