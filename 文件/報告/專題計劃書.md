## 一、計畫目標

本專題旨在設計並實作兩款功能互補、協同工作的機器人系統，模擬智慧倉儲物流場景中的「取物」與「運輸」作業。兩台機器人需在 **8 分鐘**的比賽時間內完成盡可能多次的零件搬運流程。

| 機器人 | 類型 | 操控方式 | 尺寸限制 | 核心功能 |
|--------|------|----------|---------|----------|
| **取物機器人** | 八足 Theo Jansen 連桿 | 手機藍芽遙控 | ≤ 400×400 mm | 從 S 形貨架夾取零件、暫存並轉移至運輸機器人 |
| **運輸機器人** | LEGO EV3 輪式 | 全自動循跡 | ≤ 400×300 mm | 沿黑線自動循跡行駛，將零件推落至放置區平台 |

### 競賽規則摘要

| 項目 | 規則 |
|------|------|
| 比賽時間 | 每回合 **8 分鐘** |
| 競賽制度 | 三輪競賽，取最高分計入成績 |
| 計分 | 零件放入放置區 = **1 分/個**（最高 48 分）+ 對戰分數 2 分 |
| 扣分 | 掉落零件 **-1 分/個**、機器人殘留零件 **-1 分/個** |
| 重置 | 每台有 1 次免費重置，第 2 次起每次 **-1 分** |
| 區域限制 | 取物機器人**不可進入運輸區** |
| 及格分數 | 3 分 = 百分比 70 分 |

### 目標物規格

比賽需搬運 8 種零件，每種 6 個，共 48 個：

| 零件 | 重量 | 關鍵尺寸 | 夾取難度 |
|------|------|---------|---------|
| 線性襯套 | 83.3g | 外徑 32mm | ★★★（最重、最大）|
| 大螺帽 | 69.1g | — | ★★ |
| 六角螺栓 | 56.2g | — | ★★ |
| 蝶形螺帽 | 30.2g | 有翼 | ★★★（形狀不規則）|
| 滾珠軸承 | 28.2g | 外徑 28mm | ★★ |
| 壓縮彈簧 | 17.5g | 外徑 27mm | ★★ |
| 小螺帽 | 15.6g | — | ★ |
| 拉伸彈簧 | 9.2g | 外徑 16mm | ★★ |

> **設計考量**：夾爪開口需 > 32mm（線性襯套外徑），夾持力需能穩固抓住 83.3g 零件；貨架高度為置物盤底部 156mm、邊框高 200mm，手臂需能伸入此範圍。

## 二、動機與文獻回顧

### 2.1 動機

現代倉儲物流系統朝自動化與智慧化發展，Amazon Kiva 機器人、自動導引車 (AGV) 等技術已廣泛應用於實際倉庫。本專題透過兩機協同的物流場景，將課堂所學之機械原理實際應用：

1. **連桿機構設計**：Theo Jansen 仿生八足步行機構，探索 11 桿平面連桿機構的運動合成與最佳化。
2. **夾取機構設計**：齒輪齒條 (Rack and Pinion) 平行夾爪，結合 3D 列印與雷射切割。
3. **自動控制理論**：PID 控制器應用於 EV3 運輸機器人的黑線循跡。
4. **機電整合**：ESP32 + ESP-NOW + L298N + PCA9685 伺服驅動的模組化整合。
5. **團隊工程實務**：7 人團隊從設計、加工、組裝到測試的完整工程流程。

### 2.2 Theo Jansen 連桿機構

Theo Jansen Linkage 是由荷蘭動態雕塑家 Theo Jansen 透過**遺傳演算法 (Genetic Algorithm)** 最佳化的 **11 桿平面連桿機構**，將曲柄旋轉運動轉換為仿生步行軌跡。足端軌跡下半段近似水平直線（接地段 ≥ 60%），上半段為橢圓弧。

```
              固定支點 O
                 ●
                /|\
               / | \
           a  /  |  \ b
             /   |   \
            ● M  |  N ●
           /|    |    |\
       e  / |    |c   | \ d
         /  |    |    |  \
    J ●─/─  |    |    |  \─── K ●
      | f\  |g   |    |h /|
      |   \ |    |    | / |
      |    ●─────●────●  |
      |    L     P     Q  |
      |         / \       |
   i  |        /   \      | j
      |       /     \     |
      ●──────●       ●────●
      R      足端 F        S
```

#### 與 Chebyshev 機構比較

| 特性 | Chebyshev (四桿) | Theo Jansen (11 桿) |
|------|-----------------|---------------------|
| 接地段比例 | ~50% | **~60%+** |
| 步行穩定性 | 三角步態 6 足 | **交替步態 8 足** |
| 適用性 | 高速輕量 | **負載穩定** ✅ |

| 連桿代號 | Holy Number | ×0.7 (mm) | 說明 |

| a (Crank) | 38.0 | 26.6 | 曲柄 |

| c | 39.3 | 27.5 | 固定桿 |
| d | 40.1 | 28.1 | N→K |
| e | 55.8 | 39.1 | M→J |
| f | 39.4 | 27.6 | J→L |
| g | 36.7 | 25.7 | M→L |
| h | 65.7 | 46.0 | N→Q |
| i | 49.0 | 34.3 | L→F |
| j | 50.0 | 35.0 | K→S |
| k | 61.9 | 43.3 | Q→F |

### 2.3 夾取機構技術

| 類型 | 優點 | 缺點 | 適用 |
|------|------|------|------|
| **平行型夾爪** | 夾持力均勻 | 機構稍複雜 | ✅ 本組 |
| 成角型夾爪 | 結構簡單 | 力隨開口變化 | 固定尺寸 |
| 真空吸附 | 非接觸 | 需氣源 | 平面品 |
| 磁性夾持 | 無接觸力 | 僅限金屬 | 鐵磁材料 |

本組選擇**齒輪齒條 (Rack and Pinion) 雙向平行夾爪**：370 直流減速馬達具自鎖效應，斷電仍維持夾緊；搭配微動開關 (Limit Switch) 極限保護。

### 2.4 PID 控制原理

$$u(t) = K_p \cdot e(t) + K_i \cdot \int_0^t e(\tau)\,d\tau + K_d \cdot \frac{de(t)}{dt}$$

| 項 | 控制作用 | 過大影響 | 過小影響 |
|----|---------|--------|---------|
| P | 即時修正偏差 | 震盪 | 跟蹤慢 |
| I | 消除穩態誤差 | 積分飽和 | 殘留偏移 |
| D | 抑制突變 | 噪音放大 | 無阻尼 |

本組使用單感測器左緣循跡法，目前調校參數：`KP=0.85`, `KI=0.01`, `KD=0.5`, `BASE_SPEED=110 mm/s`。

### 2.5 主控板選擇分析

在過往的專題中，Arduino Uno 常被作為控制板選擇，但其存在以下瓶頸：運算能力不足、無內建無線通訊、記憶體容量有限、無法有效多工處理、擴展性與整合能力較低。這些限制在本次多馬達控制與無線通訊的場景下將成為嚴重的效能瓶頸。

本組選擇 **ESP32** 作為主控板，其相較 Arduino 具有以下優勢：

| 特性 | ESP32 | Arduino Uno/MEGA |
|------|-------|------------------|
| 運算效能 | 雙核心 240MHz | 單核心 16MHz |
| 無線通訊 | 內建 Wi-Fi / 藍芽 | 需外接模組 |
| 記憶體 | 520KB SRAM + 4MB Flash | 8KB SRAM + 256KB Flash |
| 多工處理 | FreeRTOS 支援 | 無原生支援 |
| 擴展性 | 高整合度 | 較低 |

### 2.6 ESP-NOW 無線通訊

採用 **ESP-NOW** 協議實現 ESP32 控制板之間的點對點無線通訊，不需透過 Wi-Fi 路由器即可進行低延遲資料傳輸。透過模組化架構，ESP32 主控板負責馬達控制與遙控接收，ESP32 C3 子控板負責 Z 方向與夾爪指令，兩者透過 ESP-NOW 協調運作。此外，ESP32 內建藍芽可搭配專用遙控 App 進行手機操控。

## 五、設計概念草圖

### 5.1 取物機器人 — 系統架構

```
手機遙控 App（ESP32 內建藍芽）
    │
    ▼
ESP32（主控板）                         ESP32 C3（子控板）
    │  ┌── 馬達控制                         │  ┌── Z 方向控制
    │  ├── 遙控接收                         │  └── 夾爪指令
    │  └── 夾爪指令發送 ──── ESP-NOW ────→  │
    │                                       │
    ├── L298N (板A) → JGB37-520 左側 4 足   ├── L298N (板B) → XD-25GA 370 手臂/夾爪
    ├── Limit Switch → 夾爪極限保護          │
    ├── PCA9685 (I2C)
    │   └── SG90 承物台傾斜
    └── 電源：18650 鋰電池 × 4
```

透過 ESP-NOW 讓各個 ESP 控制板之間不需 Wi-Fi 即可做點對點通訊，在功能上設計模組化的系統。

### 5.2 取物機器人 — 八足步行機構

```
  俯視圖（↑ = 前進方向）

       前
  足1 ── 足5       左側（足1~4）→ 馬達 A (JGB37-520)
   |      |
  足2 ── 足6       右側（足5~8）→ 馬達 B (JGB37-520)
   |      |
  足3 ── 足7       差速轉向
   |      |
  足4 ── 足8       交替步態：同側相位差 90°，左右錯開 180°
       後
```

- 底盤材料：5mm 壓克力（雷切）、連桿片 3mm 壓克力
- 轉軸：M3 螺絲 + 尼龍墊圈
- 估算尺寸：長 ≈ 280mm、寬 ≈ 260mm（在 400×400mm 限制內）

### 5.3 取物機器人 — 夾取機構

```
側視圖：

         ┌─── 夾爪 ───┐
         │ [齒條齒輪]   │  ← 上層：齒輪齒條平行夾爪 + 滑軌手臂
    ─────┤             ├─────
         │  [承物台]    │  ← 下層：可傾斜承物台
    ─────┤  ↙ 絞鏈    ├─────     （一側絞鏈 + 一側伸縮桿）
         └─────────────┘
    ─────── 底盤 + 8 足 ───────
```

- **夾爪**：齒輪齒條 (Rack and Pinion) 雙向平行，3D 列印夾爪板 + 雷切齒輪 + 外購齒條
- **驅動**：XD-25GA 370 DC 減速馬達，自鎖效應保持夾緊
- **安全**：微動開關 (Limit Switch) 硬體保護 + 軟體 Timeout 保護
- **增摩**：高密度海綿 + 矽膠止滑墊
- **開口**：> 32mm（覆蓋所有零件外徑）

### 5.4 運輸機器人 — 系統架構

```
EV3 Brick (Pybricks MicroPython)
    ├── Port D: 左輪大馬達（輪徑 56mm）
    ├── Port C: 右輪大馬達（輪徑 56mm）
    ├── Port A: 輸送帶中馬達（頂部水平輸送帶）
    ├── Port S1: 前下顏色感測器（循跡+停止線，離地 5~10mm）
    └── Port S4: 觸碰感測器（啟動/零件偵測）
```

### 5.5 運輸機器人 — 機構佈局

```
        前方（行進方向 →）
    ┌──────────────────────┐
    │     [S1 前下感測器]    │  ← 顏色感測器朝下
    │   ┌────────────┐    │
    │   │  輸送帶帶面  │    │  ← 頂部水平輸送帶 (Motor A)
    │   │  →→→→→→  │    │    零件往外側推落
    │   └────────────┘    │
    │        EV3 Brick      │
    │  ◎左輪          右輪◎ │  ← Port D, C
    │     ● 萬向輪         │
    │   [觸碰感測器 S4]    │
    └──────────────────────┘
```

### 5.6 運輸機器人 — 輸送帶

```
側視圖：
                零件
     → → → → [■] → → 推落至放置區平台
    ┌═══════════════┐
    │  履帶帶面         │ ← LEGO 履帶組
    └═══════════════┘
    ◎驅動輪          ○惰輪
    (Motor A)
```

- 驅動輪靠內側（接收端），惰輪靠外側（推落端）
- 程式參數：`CONVEYOR_SPEED = 300 deg/s`、`CONVEYOR_RUN_TIME = 3000 ms`

### 5.7 雙機協同流程

```
取物機器人（遙控）                    運輸機器人（自動）
────────────────                   ────────────────
1. App 連線 ESP32                    1. 觸碰感測器啟動
2. 步行至貨架                        2. 等待於起點
3. 手臂/夾爪夾取零件                  │
4. 暫存至承物台                       │
5. 步行至運輸機器人旁                  │
6. 傾斜承物台倒入輸送帶  ──────→    3. 觸碰感測器觸發
                                      4. PID 循跡至放置區（黃線）
                                      5. 停車，啟動輸送帶推落零件
                                      6. 繼續循跡返回起點（紅線）
7. 繼續取件（重複 2~6）  ←──────    7. 停車等待下一輪
```

### 5.8 遙控 App 介面

採用 ESP32 內建藍芽搭配專用遙控 App，透過手機控制取物機器人的步行與手臂動作。App 介面包含步行控制（前進、後退、左右轉）、手臂控制（上下、伸縮）、夾爪控制（開合）、承物台控制（傾斜/水平）等功能區塊。
