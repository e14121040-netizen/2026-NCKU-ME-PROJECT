## 一、計畫目標

本專題旨在設計並實作兩款功能互補、協同工作的機器人系統，模擬智慧倉儲物流場景中的「取物」與「運輸」作業。兩台機器人需在 **8 分鐘**的比賽時間內完成盡可能多次的零件搬運流程。

| 機器人 | 類型 | 操控方式 | 尺寸限制 | 核心功能 |
|--------|------|----------|---------|----------|
| **取物機器人** | 八足 Theo Jansen 連桿 | 手機藍芽遙控 | ≤ 400×400 mm | 從 S 形貨架夾取零件、暫存並轉移至運輸機器人 |
| **運輸機器人** | LEGO EV3 輪式 | 全自動循跡 | ≤ 400×300 mm | 沿黑線自動循跡行駛，將零件推落至放置區平台 |

### 競賽規則摘要

| 項目 | 規則 |
|------|------|
| 比賽時間 | 每回合 **8 分鐘** |
| 競賽制度 | 三輪競賽，取最高分計入成績 |
| 計分 | 零件放入放置區 = **1 分/個**（最高 48 分）+ 對戰分數 2 分 |
| 扣分 | 掉落零件 **-1 分/個**、機器人殘留零件 **-1 分/個** |
| 重置 | 每台有 1 次免費重置，第 2 次起每次 **-1 分** |
| 區域限制 | 取物機器人**不可進入運輸區** |
| 及格分數 | 3 分 = 百分比 70 分 |

### 目標物規格

比賽需搬運 8 種零件，每種 6 個，共 48 個：

| 零件 | 重量 | 關鍵尺寸 | 夾取難度 |
|------|------|---------|---------|
| 線性襯套 | 83.3g | 外徑 32mm | ★★★（最重、最大）|
| 大螺帽 | 69.1g | — | ★★ |
| 六角螺栓 | 56.2g | — | ★★ |
| 蝶形螺帽 | 30.2g | 有翼 | ★★★（形狀不規則）|
| 滾珠軸承 | 28.2g | 外徑 28mm | ★★ |
| 壓縮彈簧 | 17.5g | 外徑 27mm | ★★ |
| 小螺帽 | 15.6g | — | ★ |
| 拉伸彈簧 | 9.2g | 外徑 16mm | ★★ |

> **設計考量**：夾爪開口需 > 32mm（線性襯套外徑），夾持力需能穩固抓住 83.3g 零件；貨架高度為置物盤底部 156mm、邊框高 200mm，手臂需能伸入此範圍。

## 二、動機與文獻回顧

### 2.1 動機

現代倉儲物流系統朝自動化與智慧化發展，Amazon Kiva 機器人、自動導引車 (AGV) 等技術已廣泛應用於實際倉庫。本專題透過兩機協同的物流場景，將課堂所學之機械原理實際應用：

1. **連桿機構設計**：Theo Jansen 仿生八足步行機構，探索 11 桿平面連桿機構的運動合成與最佳化。
2. **夾取機構設計**：齒輪齒條 (Rack and Pinion) 平行夾爪，結合 3D 列印與雷射切割。
3. **自動控制理論**：PID 控制器應用於 EV3 運輸機器人的黑線循跡。
4. **機電整合**：Arduino MEGA + L298N + HC-05 藍芽 + PCA9685 伺服驅動的多層次整合。
5. **團隊工程實務**：7 人團隊從設計、加工、組裝到測試的完整工程流程。

### 2.2 Theo Jansen 連桿機構

Theo Jansen Linkage 是由荷蘭動態雕塑家 Theo Jansen 透過**遺傳演算法 (Genetic Algorithm)** 最佳化的 **11 桿平面連桿機構**，將曲柄旋轉運動轉換為仿生步行軌跡。足端軌跡下半段近似水平直線（接地段 ≥ 60%），上半段為橢圓弧。

```
              固定支點 O
                 ●
                /|\
               / | \
           a  /  |  \ b
             /   |   \
            ● M  |  N ●
           /|    |    |\
       e  / |    |c   | \ d
         /  |    |    |  \
    J ●─/─  |    |    |  \─── K ●
      | f\  |g   |    |h /|
      |   \ |    |    | / |
      |    ●─────●────●  |
      |    L     P     Q  |
      |         / \       |
   i  |        /   \      | j
      |       /     \     |
      ●──────●       ●────●
      R      足端 F        S
```

#### 與 Chebyshev 機構比較

| 特性 | Chebyshev (四桿) | Theo Jansen (11 桿) |
|------|-----------------|---------------------|
| 接地段比例 | ~50% | **~60%+** |
| 步行穩定性 | 三角步態 6 足 | **交替步態 8 足** |
| 適用性 | 高速輕量 | **負載穩定** ✅ |

| 連桿代號 | Holy Number | ×0.7 (mm) | 說明 |

| a (Crank) | 38.0 | 26.6 | 曲柄 |

| c | 39.3 | 27.5 | 固定桿 |
| d | 40.1 | 28.1 | N→K |
| e | 55.8 | 39.1 | M→J |
| f | 39.4 | 27.6 | J→L |
| g | 36.7 | 25.7 | M→L |

| j | 50.0 | 35.0 | K→S |
| k | 61.9 | 43.3 | Q→F |

### 2.3 夾取機構技術

| 類型 | 優點 | 缺點 | 適用 |
|------|------|------|------|
| **平行型夾爪** | 夾持力均勻 | 機構稍複雜 | ✅ 本組 |
| 成角型夾爪 | 結構簡單 | 力隨開口變化 | 固定尺寸 |
| 真空吸附 | 非接觸 | 需氣源 | 平面品 |
| 磁性夾持 | 無接觸力 | 僅限金屬 | 鐵磁材料 |

本組選擇**齒輪齒條 (Rack and Pinion) 雙向平行夾爪**：370 直流減速馬達具自鎖效應，斷電仍維持夾緊；搭配微動開關 (Limit Switch) 極限保護。

### 2.4 PID 控制原理

$$u(t) = K_p \cdot e(t) + K_i \cdot \int_0^t e(\tau)\,d\tau + K_d \cdot \frac{de(t)}{dt}$$

| 項 | 控制作用 | 過大影響 | 過小影響 |
|----|---------|--------|---------|
| P | 即時修正偏差 | 震盪 | 跟蹤慢 |
| I | 消除穩態誤差 | 積分飽和 | 殘留偏移 |
| D | 抑制突變 | 噪音放大 | 無阻尼 |

本組使用單感測器左緣循跡法，目前調校參數：`KP=0.85`, `KI=0.01`, `KD=0.5`, `BASE_SPEED=110 mm/s`。

### 2.5 藍芽無線通訊

採用 HC-05 藍芽模組（SPP 協議，鮑率 38400），單字元指令協議實現低延遲控制（< 0.5 秒）。

## 五、設計概念草圖

### 5.1 取物機器人 — 系統架構

```
手機 App (App Inventor)
    │  藍芽 (HC-05, 38400 baud)
    ▼
Arduino MEGA 2560
    ├── L298N (板A)  ── Pin 40,41 + Pin 9    → JGB37-520 左側 4 足
    │                ── Pin 42,43 + Pin 10   → JGB37-520 右側 4 足
    ├── L298N (板B)  ── [待定 Pin]            → XD-25GA 370 手臂伸縮
    │                ── [待定 Pin]            → XD-25GA 370 夾爪開合
    ├── Limit Switch ── [待定 Pin]            → 夾爪極限保護
    ├── PCA9685 (I2C: SDA=20, SCL=21)
    │   └── CH3: SG90/MG90S 承物台傾斜
    ├── HC-05 (Serial1: TX=18, RX=19)
    └── 電源：11.1V 鋰電池 → LM2596 降壓 → Arduino Vin
```

### 5.2 取物機器人 — 八足步行機構

```
  俯視圖（↑ = 前進方向）

       前
  足1 ── 足5       左側（足1~4）→ 馬達 A (JGB37-520)
   |      |
  足2 ── 足6       右側（足5~8）→ 馬達 B (JGB37-520)
   |      |
  足3 ── 足7       差速轉向
   |      |
  足4 ── 足8       交替步態：同側相位差 90°，左右錯開 180°
       後
```

- 底盤材料：5mm 壓克力（雷切）、連桿片 3mm 壓克力
- 轉軸：M3 螺絲 + 尼龍墊圈
- 估算尺寸：長 ≈ 280mm、寬 ≈ 260mm（在 400×400mm 限制內）

### 5.3 取物機器人 — 夾取機構

```
側視圖：

         ┌─── 夾爪 ───┐
         │ [齒條齒輪]   │  ← 上層：齒輪齒條平行夾爪 + 滑軌手臂
    ─────┤             ├─────
         │  [承物台]    │  ← 下層：可傾斜承物台
    ─────┤  ↙ 絞鏈    ├─────     （一側絞鏈 + 一側伸縮桿）
         └─────────────┘
    ─────── 底盤 + 8 足 ───────
```

- **夾爪**：齒輪齒條 (Rack and Pinion) 雙向平行，3D 列印夾爪板 + 雷切齒輪 + 外購齒條
- **驅動**：XD-25GA 370 DC 減速馬達，自鎖效應保持夾緊
- **安全**：微動開關 (Limit Switch) 硬體保護 + 軟體 Timeout 保護
- **增摩**：高密度海綿 + 矽膠止滑墊
- **開口**：> 32mm（覆蓋所有零件外徑）

### 5.4 運輸機器人 — 系統架構

```
EV3 Brick (Pybricks MicroPython)
    ├── Port D: 左輪大馬達（輪徑 56mm）
    ├── Port C: 右輪大馬達（輪徑 56mm）
    ├── Port A: 輸送帶中馬達（頂部水平輸送帶）
    ├── Port S1: 前下顏色感測器（循跡+停止線，離地 5~10mm）
    └── Port S4: 觸碰感測器（啟動/零件偵測）
```

### 5.5 運輸機器人 — 機構佈局

```
        前方（行進方向 →）
    ┌──────────────────────┐
    │     [S1 前下感測器]    │  ← 顏色感測器朝下
    │   ┌────────────┐    │
    │   │  輸送帶帶面  │    │  ← 頂部水平輸送帶 (Motor A)
    │   │  →→→→→→  │    │    零件往外側推落
    │   └────────────┘    │
    │        EV3 Brick      │
    │  ◎左輪          右輪◎ │  ← Port D, C
    │     ● 萬向輪         │
    │   [觸碰感測器 S4]    │
    └──────────────────────┘
```

### 5.6 運輸機器人 — 輸送帶

```
側視圖：
                零件
     → → → → [■] → → 推落至放置區平台
    ┌═══════════════┐
    │  履帶帶面         │ ← LEGO 履帶組
    └═══════════════┘
    ◎驅動輪          ○惰輪
    (Motor A)
```

- 驅動輪靠內側（接收端），惰輪靠外側（推落端）
- 程式參數：`CONVEYOR_SPEED = 300 deg/s`、`CONVEYOR_RUN_TIME = 3000 ms`

### 5.7 雙機協同流程

```
取物機器人（遙控）                    運輸機器人（自動）
────────────────                   ────────────────
1. App 連線藍芽                      1. 觸碰感測器啟動

3. 手臂/夾爪夾取零件                  │
```
