# 遙控 App — 指令對照表

## 藍芽設定

> 本組使用 **ESP32 內建藍芽（Classic BT 或 BLE）** 連線遙控 App，無需 HC-05 模組。
> - BluetoothSerial 版：裝置名稱 `PickupRobot`
> - BLE 版：裝置名稱 `ESP32_MainController`
> - ESP32 主控板 USB 插電腦供電，透過 ESP-NOW 無線控制機器人

## 指令字元對照

### 步行控制（→ C3 #1 腿部子控板）

| 按鈕 | 發送字元 | 功能 | 觸發方式 |
|------|---------|------|----------|
| ▲ | `f` | 前進（全速） | 按住發送 |
| ▼ | `b` | 後退（全速） | 按住發送 |
| ◀ | `l` | 原地左旋 | 按住發送 |
| ▶ | `r` | 原地右旋 | 按住發送 |
| ▲(慢) | `F` | 前進（半速） | 按住發送 |
| ▼(慢) | `B` | 後退（半速） | 按住發送 |
| ◀(慢) | `L` | 原地左旋（半速） | 按住發送 |
| ▶(慢) | `R` | 原地右旋（半速） | 按住發送 |
| ↺ | `q` | 原地左旋 | 按住發送 |
| ↻ | `e` | 原地右旋 | 按住發送 |
| ⬜ | `0` | 全部停止 | **放開時發送** |

> ⚠ `l`/`r` 與 `q`/`e` 功能相同（皆為原地旋轉），不使用差速轉向以避免重心不穩。

### 大圓盤 + z 控制（→ C3 #2 大圓盤+z 子控板）

| 按鈕 | 發送字元 | 功能 | 觸發方式 |
|------|---------|------|----------|
| 左轉 | `a` | 大圓盤左轉 | 按住發送 |
| 右轉 | `d` | 大圓盤右轉 | 按住發送 |
| z↑ | `u` | z 方向上升 | 按住發送 |
| z↓ | `j` | z 方向下降 | 按住發送 |

> 大圓盤使用 XD-25GA 370 直流減速馬達（自鎖），按住持續旋轉、放開停止。
> z 升降使用 JGY370 蝸桿減速馬達（自鎖），斷電不會下滑。

### Servo / 夾爪控制（→ C3 #3 Servo 子控板）

| 按鈕 | 發送字元 | 功能 | 觸發方式 |
|------|---------|------|----------|
| 伸出 | `w` | r 齒條伸出 | 按住發送 |
| 縮回 | `s` | r 齒條縮回 | 按住發送 |
| θ+ | `i` | 夾爪 θ 旋轉（正） | 單擊發送 |
| θ- | `k` | 夾爪 θ 旋轉（反） | 單擊發送 |
| 爪開 | `o` | 夾爪張開 | 單擊發送 |
| 爪合 | `p` | 夾爪閉合 | 單擊發送 |
| 擋開 | `g` | 承物盒擋板打開 | 單擊發送 |
| 擋關 | `n` | 承物盒擋板關閉 | 單擊發送 |
| 歸位 | `h` | 歸位（r 縮回 + 夾爪張開 + 擋板關閉） | 單擊發送 |

> r 齒條使用 MG996R 360° 連續旋轉舵機，人眼判斷位置，按住伸出/縮回、放開停止。
> θ 旋轉和夾爪開合使用 MG996R 180° 標準伺服，一次到位。
> 承物盒擋板使用 MG996R 180° 標準伺服，旋轉門式開合。

## 注意事項

- 步行按鈕使用 **TouchDown + TouchUp**（按住移動、放開停止）
- 大圓盤 / z 升降 / r 齒條同樣使用 **TouchDown + TouchUp**（DC 馬達或 360° Servo 持續動作）
- θ 旋轉 / 夾爪開合 / 擋板開合 按鈕使用 **Click**（180° 伺服馬達一次到位）
- BLE 版還支援字串指令（如 `FORWARD`, `STOP`, `SPD:200`），詳見 [esp32控制/README.md](../../esp32控制/README.md)
- ⚠ 指令字元已因架構調整而變動，程式碼需同步更新
