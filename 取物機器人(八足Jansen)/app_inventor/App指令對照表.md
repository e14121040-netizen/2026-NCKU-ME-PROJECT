# 遙控 App — 指令對照表

## 藍芽設定

> 本組使用 **ESP32 內建藍芽（Classic BT 或 BLE）** 連線遙控 App，無需 HC-05 模組。
> - BluetoothSerial 版：裝置名稱 `PickupRobot`
> - BLE 版：裝置名稱 `ESP32_MainController`

## 指令字元對照

### 步行控制（→ C3 #1 腿部子控板）

| 按鈕 | 發送字元 | 功能 | 觸發方式 |
|------|---------|------|----------|
| ▲ | `f` | 前進（全速） | 按住發送 |
| ▼ | `b` | 後退（全速） | 按住發送 |
| ◀ | `l` | 左轉 | 按住發送 |
| ▶ | `r` | 右轉 | 按住發送 |
| ▲(慢) | `F` | 前進（半速） | 按住發送 |
| ▼(慢) | `B` | 後退（半速） | 按住發送 |
| ◀(慢) | `L` | 左轉（半速） | 按住發送 |
| ▶(慢) | `R` | 右轉（半速） | 按住發送 |
| ↺ | `q` | 原地左旋轉 | 按住發送 |
| ↻ | `e` | 原地右旋轉 | 按住發送 |
| ⬜ | `0` | 全部停止 | **放開時發送** |

### 手臂 r/θ 控制（→ C3 #2 手臂子控板）

| 按鈕 | 發送字元 | 功能 | 觸發方式 |
|------|---------|------|----------|
| 伸出 | `w` | 手臂伸出 (r+) | 按住發送 |
| 縮回 | `s` | 手臂縮回 (r-) | 按住發送 |
| 左轉 | `a` | 手臂左轉 (θ-) | 按住發送 |
| 右轉 | `d` | 手臂右轉 (θ+) | 按住發送 |

> 手臂使用 XD-25GA 370 直流減速馬達（自鎖），按住持續旋轉、放開停止。

### z/夾爪控制（→ C3 #3 z/夾爪子控板）

| 按鈕 | 發送字元 | 功能 | 觸發方式 |
|------|---------|------|----------|
| z↑ | `u` | z 方向上升 | 按住發送 |
| z↓ | `j` | z 方向下降 | 按住發送 |
| 爪開 | `o` | 夾爪張開 | 單擊發送 |
| 爪合 | `p` | 夾爪閉合 | 單擊發送 |
| 傾斜 | `t` | 蓋板開（承物台傾斜） | 單擊發送 |
| 水平 | `y` | 蓋板關（承物台水平） | 單擊發送 |
| 歸位 | `h` | 歸位（z 下降到底 + 夾爪張開 + 蓋板關） | 單擊發送 |

## App 介面設計建議

### 介面佈局（橫式，三區域設計）

```
┌────────────────────────────────────────────────────────┐
│  [連線藍芽]                                [斷開]      │
│                                                        │
│   步行控制              手臂 r/θ       z/夾爪控制      │
│       [▲]              [伸出 w]       [z↑ u]          │
│   [◀] [⬜] [▶]        [左 a] [右 d]   [爪開 o][爪合 p]│
│       [▼]              [縮回 s]       [z↓ j]          │
│                                                        │
│   [↺]     [↻]                        [傾斜 t][水平 y] │
│                                       [歸位 h]        │
│   [ 慢速模式 切換 ]                                    │
└────────────────────────────────────────────────────────┘
```

## 注意事項

- 步行按鈕使用 **TouchDown + TouchUp**（按住移動、放開停止）
- 手臂 r/θ 同樣使用 **TouchDown + TouchUp**（DC 馬達持續動作）
- 夾爪/蓋板按鈕使用 **Click**（伺服馬達一次到位）
- BLE 版還支援字串指令（如 `FORWARD`, `STOP`, `SPD:200`），詳見 [esp32控制/README.md](../../esp32控制/README.md)
