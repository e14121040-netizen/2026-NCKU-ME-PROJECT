### 規格參數

| **工作電壓** | 12V DC |

| **額定電流** | ~1.2A |

### 扭矩單位換算

| 表示法 | 額定扭矩 | 堵轉扭矩 |
|--------|---------|---------|
| kg·cm | 1.0 ~ 1.5 | 3.0 ~ 4.5 |
| N·cm | 9.8 ~ 14.7 | 29.4 ~ 44.1 |
| N·m | 0.098 ~ 0.147 | 0.294 ~ 0.441 |
| oz·in | 13.9 ~ 20.8 | 41.7 ~ 62.5 |

### 應用分析

```
用途：左右各 1 顆馬達驅動八足 Theo Jansen 連桿步行
      差速轉向（左右馬達獨立速度控制）

負載估算：
  - 機器人總重量（預估）：~2~3 kg（含電池、機構、夾爪）
  - 八足均分負載：每側 4 足 ≈ 承擔 ~1~1.5 kg
  - 以 0.7 縮放因子的 Theo Jansen 連桿計算
  - 曲柄半徑 r ≈ 15mm = 1.5cm（估算）
  - 所需扭矩 T = F × r = 1.5 kg × 1.5 cm = 2.25 kg·cm

安全裕度：
  - 額定扭矩 1.0~1.5 kg·cm → ⚠ 可能接近或超過額定值
  - 堵轉扭矩 3.0~4.5 kg·cm → ✅ 有餘裕，但不應長時間堵轉
  - 建議：實測時監控電流，若常態超過 2A 表示負載過大
```

> ⚠ **注意**：JGB37-520 是系列型號，不同供應商的齒輪箱精確規格可能有差異。建議以實測電流反推實際負載扭矩。

### 假設使用低 RPM 版本（~10~30 RPM，適合升降）

| 表示法 | 額定扭矩（估） | 堵轉扭矩（估） |
|--------|------------|-------------|
| kg·cm | 10 ~ 20 | 15 ~ 30 |
| N·cm | 98 ~ 196 | 147 ~ 294 |
| N·m | 0.98 ~ 1.96 | 1.47 ~ 2.94 |

### 應用分析

```
用途：z 方向升降（垂直提升夾爪機構）

負載估算：
  - 需提升的載重：夾爪 + 手臂 + 夾取物品 ≈ 500g ~ 1kg
  - 升降機構的導螺桿導程或齒輪半徑：取決於機構設計
  - 假設升降螺桿導程 = 8mm/rev → 提升 1kg 所需扭矩：
    T = (m × g × lead) / (2π × η)
    T = (1 × 9.8 × 0.008) / (2π × 0.3)  ← η=0.3（蝸桿效率）
    T ≈ 0.042 N·m ≈ 0.42 kg·cm

安全裕度：
  - 即使是低減速比版本，額定扭矩 > 10 kg·cm
  - 所需扭矩 < 1 kg·cm → ✅ 極為充裕
  - 蝸桿自鎖 → ✅ 斷電不會下滑，安全性極佳
  - 結論：z 升降的扭矩完全足夠，自鎖特性是關鍵優勢
```

### 1. 腿部步行馬達（JGB37-520 ×2）— 整機最大承載

```
反推公式：
  T_avail = T_rated × 2（左右兩顆馬達合計）
  F_max = T_avail / r_crank

參數：
  T_rated（單顆） = 1.0 ~ 1.5 kg·cm
  T_rated（雙顆合計） = 2.0 ~ 3.0 kg·cm
  T_stall（雙顆合計） = 6.0 ~ 9.0 kg·cm
  曲柄半徑 r ≈ 1.5cm

最大可驅動負重（額定扭矩，持續運轉安全值）：
  m_rated = T_rated_total / r = 3.0 / 1.5 = 2.0 kg

最大可驅動負重（堵轉扭矩，瞬間極限值）：
  m_stall = T_stall_total / r = 9.0 / 1.5 = 6.0 kg
```

| 指標 | 數值 |
|------|------|
| **持續安全承載** | **≤ 2.0 kg**（含機器人自重） |
| **瞬間極限承載** | **≤ 6.0 kg**（含機器人自重，不可持續） |
| 機器人空載重量（預估） | ~2.0 ~ 2.5 kg |
| **可額外搭載零件** | **0 ~ 0.5 kg（額定）/ ~3.5 kg（極限）** |

```
比賽應用評估：
  - 機器人自重 ≈ 2.0 ~ 2.5 kg
  - 可額外承載零件 ≈ 0 ~ 500g（持續安全運轉）
  - 以最重零件「線性襯套 83.3g」計算 → 最多約 6 個
  - 以平均零件重量 ~38.7g 計算 → 最多約 12 個
  - 一次搬運 6~12 個零件 → ✅ 一次處理 1~2 筆訂單

  ⚠ 如果機器人自重超過 2.5 kg：
     → 額定扭矩幾乎無餘裕，須依賴堵轉扭矩區間運作
     → 馬達電流升高，溫度上升，建議限制連續步行 < 3 分鐘
```

> ⚠ **腿部承載是整個系統的瓶頸**。機器人自重 + 搭載零件應盡量控制在 2.5 kg 以內。

### 2. 大圓盤旋轉馬達（XD-25GA 370）— 旋轉承載

```
反推公式：
  大圓盤旋轉不直接承受垂直載重（由軸承支撐）
  旋轉所需扭矩主要來自摩擦力矩和偏心力矩

  T_friction = μ × m × g × R_bearing
  T_eccentric = m_load × g × d_offset

參數：
  T_rated = 5 ~ 8 kg·cm
  軸承摩擦係數 μ ≈ 0.01（推力軸承）~ 0.3（無軸承滑動）
  軸承半徑 R ≈ 2cm

最大可旋轉載重（假設 μ=0.1，R=2cm）：
  m_max = T_rated / (μ × g × R)
        = 5 / (0.1 × 0.98 × 2)
        = 5 / 0.196
        ≈ 25.5 kg
```

| 指標 | 數值 |
|------|------|
| **最大旋轉承載** | **≫ 5 kg**（遠超需求） |
| 實際旋轉載重 | 夾爪 + 物品 ≈ 300 ~ 500g |
| 安全裕度 | ✅ **>10x** |

> ✅ 大圓盤的旋轉承載不是瓶頸。

### 3. z 升降馬達（JGY370 蝸桿）— 垂直提升承載

```
反推公式（螺桿傳動）：
  m_max = (T_rated × 2π × η) / (g × lead)

參數：
  T_rated = 10 ~ 20 kg·cm = 0.98 ~ 1.96 N·m
  η = 0.3（蝸桿效率保守值）
  lead = 8mm/rev = 0.008 m/rev
  g = 9.8 m/s²

最大提升載重：
  m_max = (0.98 × 2π × 0.3) / (9.8 × 0.008)
        = (0.98 × 1.885) / 0.0784
        = 1.847 / 0.0784
        ≈ 23.6 kg

  （取高扭矩端）
  m_max_high = (1.96 × 1.885) / 0.0784 ≈ 47.1 kg
```

| 指標 | 數值 |
|------|------|
| **最大垂直提升** | **23.6 ~ 47.1 kg**（理論值） |
| 實際提升載重 | 夾爪 + 手臂 + 物品 ≈ 500g ~ 1 kg |
| 安全裕度 | ✅ **>23x** |

> ✅ z 升降的承載能力極為充裕，完全不是瓶頸。蝸桿自鎖確保斷電不下滑。

### 4. r 齒條伸縮（MG996R 360°）— 水平推送承載

```
反推公式：
  齒條為水平移動，主要克服摩擦力
  F_max = T_stall / r_gear

參數：
  T_stall = ~10 kg·cm = 98 N·cm
  齒輪節圓半徑 r ≈ 1.5cm

最大推送力：
  F_max = 98 / 1.5 ≈ 65 N ≈ 6.6 kg

可承載重量（假設滑軌摩擦係數 μ=0.1）：
  m_max = F_max / (μ × g)
        = 65 / (0.1 × 9.8)
        ≈ 66 kg（水平推送時）

可懸吊重量（齒條垂直向下伸出時的最差情況）：
  m_max_vertical = T_stall / (g × r)
                 = 98 / (9.8 × 1.5)
                 ≈ 6.7 kg
```

| 指標 | 數值 |
|------|------|
| **最大水平推送力** | **~65 N（≈ 6.6 kgf）** |
| **最大垂直懸吊** | **~6.7 kg** |
| 實際載重 | 夾爪末端 + 物品 ≈ 200 ~ 400g |
| 安全裕度 | ✅ **>16x** |

> ✅ r 齒條承載不是瓶頸。

### 5. 夾爪 θ 旋轉（MG996R 180°）— 手臂末端承載

```
反推公式：
  m_max = T_stall / (g × L_arm)

參數：
  T_stall = ~10 kg·cm = 98 N·cm
  手臂長度 L ≈ 5cm（從旋轉軸到夾爪末端）

最大末端承載：
  m_max = 98 / (9.8 × 5) = 98 / 49 = 2.0 kg

  （若臂長 L = 3cm）：
  m_max = 98 / (9.8 × 3) = 98 / 29.4 = 3.3 kg
```

| 指標 | 數值 |
|------|------|
| **最大末端承載（L=5cm）** | **~2.0 kg** |
| **最大末端承載（L=3cm）** | **~3.3 kg** |
| 最重零件（線性襯套） | 83.3g |
| 安全裕度（單件） | ✅ **>24x** |

> ✅ 夾爪旋轉可輕鬆承載任何比賽零件。

### 6. 夾爪開合（MG996R 180°）— 夾持力

```
反推公式：
  F_grip = T_stall / r_mechanism

參數：
  T_stall = ~10 kg·cm = 98 N·cm
  夾爪齒條半徑 r ≈ 1cm

最大夾持力：
  F_grip = 98 / 1 = 98 N ≈ 10 kgf

可夾持的最大重量（靠摩擦力支撐，μ=0.5 止滑墊）：
  m_max = F_grip × μ / g
        = 98 × 0.5 / 9.8
        = 5.0 kg
```

| 指標 | 數值 |
|------|------|
| **最大夾持力** | **~98 N（≈ 10 kgf）** |
| **靠摩擦可夾住** | **~5.0 kg**（含止滑墊） |
| 最重零件（線性襯套） | 83.3g |
| 安全裕度（單件） | ✅ **>60x** |

> ✅ 夾爪的夾持力完全不是問題。

## 風險評估與建議

### 🔴 高風險：腿部馬達（JGB37-520）

```
問題：安全裕度最低，額定扭矩僅 1.0~1.5 kg·cm，
      機器人滿載時所需扭矩可能達到 2.25 kg·cm。

風險：
  1. 長時間運轉可能超過額定扭矩，導致馬達過熱
  2. 上坡或不平路面時堵轉風險高
  3. 電流持續在 2~3A 範圍，接近 BTS7960 正常設計值

建議：
  ✅ 減輕機器人重量（輕量化設計）
  ✅ 使用更高減速比版本（如 60 RPM 版，扭矩更大）
  ✅ 監控馬達溫度和電流
  ✅ 限制持續運轉時間
  ✅ 八足連桿設計確保足部分擔負載均勻
```

### 🟢 低風險：夾爪系統（MG996R + XD-25GA 370 + JGY370）

```
所有夾爪相關馬達的安全裕度均 ≥ 5x，扭矩非常充裕。
蝸桿自鎖和 Servo PWM 保持功能確保斷電安全。
```

## 附錄：扭矩計算公式

### DC 馬達扭矩-轉速關係

```
T = T_stall × (1 - ω/ω_no_load)

其中：
  T_stall = 堵轉扭矩（ω = 0 時的最大扭矩）
  ω_no_load = 空載轉速（T = 0 時的最大轉速）
  T = 在轉速 ω 時的可用扭矩
```

### 升降所需扭矩（螺桿傳動）

```
T = (m × g × lead) / (2π × η)

其中：
  m = 載重質量 (kg)
  g = 重力加速度 (9.8 m/s²)
  lead = 螺桿導程 (m/rev)
  η = 傳動效率（蝸桿 ≈ 0.3~0.5）
```

### 齒條驅動所需扭矩

```
T = F × r

其中：
  F = 移動齒條所需的力 (N)
  r = 驅動齒輪節圓半徑 (m)
```

### 旋轉機構所需扭矩

```
T = m × g × L

其中：
  m = 旋轉物體質量 (kg)
  g = 重力加速度 (9.8 m/s²)
  L = 質心到旋轉軸的距離 (m)
```
