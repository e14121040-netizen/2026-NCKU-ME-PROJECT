# 取物機器人 — 接線圖

> 本文件列出取物機器人所有電路接線。  
> 已更新為 ESP32 + ESP32-C3 ×3 + ESP-NOW 分散式模組化架構。  
> ⚠ **最後更新：2026/05/12** — 新增保險絲、端子台分電架構，禁止麵包板分電。

## 系統供電架構

```
18650 鋰電池 × 4（四節電池盒，串聯 ≈ 14.8V~16.8V）
    │
    │  ← 18AWG 矽膠線
    │
    ├── 【10A 保險絲】── 正極端子台（≥6 位）
    │                       ├──→ BTS7960 #1 B+（左腿，18AWG）
    │                       ├──→ BTS7960 #2 B+（右腿，18AWG）
    │                       ├──→ BTS7960 #3 B+（大圓盤，18AWG）
    │                       ├──→ BTS7960 #4 B+（z 升降，18AWG）
    │                       ├──→ XL4015 IN+（20AWG）
    │                       └──→ LM2596 IN+（22AWG）
    │
    └── GND 端子台（≥7 位）
                            ├──→ BTS7960 #1 B-（18AWG）
                            ├──→ BTS7960 #2 B-（18AWG）
                            ├──→ BTS7960 #3 B-（18AWG）
                            ├──→ BTS7960 #4 B-（18AWG）
                            ├──→ XL4015 IN-（20AWG）
                            ├──→ LM2596 IN-（22AWG）
                            └──→ C3 #1/#2/#3 GND

    BTS7960 #1 M+/M- → JGB37-520 左腿（左側 4 足）
    BTS7960 #2 M+/M- → JGB37-520 右腿（右側 4 足）
    BTS7960 #3 M+/M- → XD-25GA 370 夾爪底部大圓盤旋轉
    BTS7960 #4 M+/M- → JGY370 z 方向升降（12V 蝸桿自鎖）

    XL4015 → 5V【Servo 專用電源】
        ├── MG996R 360°（r 齒條伸縮）── 信號線接 C3 #3 GPIO
        ├── MG996R 180°（夾爪 θ 旋轉）── 信號線接 C3 #3 GPIO
        ├── MG996R 180°（夾爪開合）── 信號線接 C3 #3 GPIO
        ├── MG996R 180°（承物盒擋板）── 信號線接 C3 #3 GPIO
        └── ⚡ 輸出端並聯 1000μF 電解電容 + 100nF 陶瓷電容

    LM2596 → 5V【MCU 專用電源】
        ├── ESP32-C3 #1（腿部子控板）
        ├── ESP32-C3 #2（大圓盤 + z 子控板）
        └── ESP32-C3 #3（Servo 子控板）

ESP32 主控板 → USB 插電腦供電（獨立電源，透過 ESP-NOW 無線通訊）
```

> ⚠ **重要**：
> - 🔥 **嚴禁使用麵包板 (breadboard) 分配 12V 電源** — 麵包板觸點僅額定 ~1A，會燒毀
> - 🔥 **嚴禁使用杜邦線 (28AWG) 作為電源線** — 杜邦線僅額定 1.4A，僅適用於信號線
> - ✅ 電源分配必須使用**端子台 (terminal block)** + **18AWG 矽膠線**
> - ✅ 電池正極必須串聯 **10A 保險絲**，防止短路時燒毀線材
> - Servo 電源（XL4015）與 MCU 電源（LM2596）**必須分開**，避免 Servo 突波造成 ESP32 重啟
> - 所有模組的 **GND 必須共地**（電池 GND = BTS7960 GND = XL4015 GND = LM2596 GND = C3 GND）
> - ESP32 主控插電腦時不需與機器人共地（ESP-NOW 是無線通訊）

## 電流估算

### 12V 側（電池直供 BTS7960）

| 負載 | 正常電流 | 峰值電流（堵轉） |
|------|---------|-----------------|
| JGB37-520 × 2（腿部行走，BTS7960 #1/#2） | ~2.4A | ~10A |
| XD-25GA 370 × 1（大圓盤，BTS7960 #3） | ~0.5A | ~2A |
| JGY370 × 1（z 升降，BTS7960 #4） | ~0.5A | ~1.5~3A |
| **12V 總計** | **~3.4A** | **~15A（極端）** |

### 5V 側 — XL4015（Servo 專用，最大 5A）

| 負載 | 正常電流 | 峰值電流 |
|------|---------|---------|
| MG996R × 4（動作中） | ~2.0A | ~10A（4 顆同時堵轉） |

> ⚠ 避免 4 顆 Servo 同時堵轉。正常操作（1~2 顆同時動作）在 5A 額定內安全。

### 5V 側 — LM2596（MCU 專用，最大 3A）

| 負載 | 電流 |
|------|------|
| ESP32-C3 × 3 | ~0.3A |
| **MCU 總計** | **~0.3A** ✅ 綽綽有餘 |

## ESP32-C3 #1 ↔ BTS7960 ×2（腿部步行馬達）

> **注意**：GPIO 腳位依 ESP32-C3 Super Mini 實際可用 GPIO 分配。
> BTS7960 每個模組只控制 **1 顆馬達**，左右腿各需 1 個模組。

```
ESP32-C3 #1            BTS7960 #1（左腿）
───────────            ──────────────────
GPIO 0 (PWM)     ──→  RPWM ─┐
GPIO 1 (PWM)     ──→  LPWM ─┤── M+/M-：JGB37-520（左側 4 足）
                       R_EN ──→ 接 3.3V（常開）
                       L_EN ──→ 接 3.3V（常開）

ESP32-C3 #1            BTS7960 #2（右腿）
───────────            ──────────────────
GPIO 3 (PWM)     ──→  RPWM ─┐
GPIO 4 (PWM)     ──→  LPWM ─┤── M+/M-：JGB37-520（右側 4 足）
                       R_EN ──→ 接 3.3V（常開）
                       L_EN ──→ 接 3.3V（常開）

GND              ──→  GND   (共地)
```

> **BTS7960 控制原理**：
> - 正轉：RPWM 輸出 PWM duty，LPWM = 0
> - 反轉：RPWM = 0，LPWM 輸出 PWM duty
> - 停止：RPWM = 0，LPWM = 0（馬達浮接）
>
> **R_EN / L_EN 說明**：
> - 接 3.3V 表示驅動器常開，不佔 GPIO
> - 若未來需要硬體急停功能，可改接 GPIO 控制（拉 LOW = 馬達浮接）

## ESP32-C3 #2 ↔ BTS7960 #3 + #4（大圓盤 + z 升降）

> 大圓盤使用 BTS7960 #3，z 升降使用 BTS7960 #4。全部 MOSFET H-Bridge，無 L298N。

```
ESP32-C3 #2            BTS7960 #3（大圓盤）
───────────            ──────────────────
GPIO 0 (PWM)     ──→  RPWM ─┐
GPIO 1 (PWM)     ──→  LPWM ─┤── M+/M-：XD-25GA 370（夾爪底部大圓盤）
                       R_EN ──→ 接 3.3V（常開）
                       L_EN ──→ 接 3.3V（常開）

ESP32-C3 #2            BTS7960 #4（z 升降）
───────────            ──────────────────
GPIO 3 (PWM)     ──→  RPWM ─┐
GPIO 4 (PWM)     ──→  LPWM ─┤── M+/M-：JGY370（z 方向升降，蝸桿自鎖）
                       R_EN ──→ 接 3.3V（常開）
                       L_EN ──→ 接 3.3V（常開）

GND              ──→  GND   (共地)
```

> R_EN/L_EN 接 3.3V 常開，不佔 GPIO。GPIO 5, 6 空出備用。

### 限位開關（ESP32-C3 #2）

```
GPIO 7  ──→ 大圓盤左極限 (Limit Switch, 常開 NO, 接 GND)
GPIO 8  ──→ 大圓盤右極限
GPIO 9  ──→ z 上升極限
GPIO 10 ──→ z 下降極限
```

> **接法**：GPIO ---- Limit Switch (NO) ---- GND，使用 `INPUT_PULLUP`  
> ⚠ 如果大圓盤不需要限位開關（可 360° 自由旋轉），可將 GPIO 7, 8 省下備用。

## ESP32-C3 #3 — Servo 控制（r 齒條 + θ 旋轉 + 夾爪開合 + 承物盒擋板）

```
ESP32-C3 #3            伺服馬達
───────────            ────────
GPIO 0 (PWM)     ──→  MG996R 360°（r 齒條伸縮）── 信號線
GPIO 1 (PWM)     ──→  MG996R 180°（夾爪 θ 旋轉）── 信號線
GPIO 2 (PWM)     ──→  MG996R 180°（夾爪開合）── 信號線

限位開關：
GPIO 4           ──→  r 齒條伸出極限 (NO, 接 GND)
GPIO 5           ──→  r 齒條縮回極限 (NO, 接 GND)

GND              ──→  共地
```

> **Servo 電源接線**：
> - V+（紅線）──→ XL4015 5V 輸出（**不是** C3 的 3.3V/5V pin）
> - GND（棕線）──→ 共地（XL4015 GND = C3 GND = 電池 GND）
> - 信號線（橘線）──→ C3 #3 對應 GPIO

> ⚠ **r 齒條限位開關**：齒條伸到底或縮到底時觸發，軟體端收到信號後立即停止 360° Servo，防止齒條過行程。

### C3 #3 GPIO 使用總結

| GPIO | 用途 |
|------|------|
| 0 | MG996R 360° PWM（r 齒條） |
| 1 | MG996R 180° PWM（θ 旋轉） |
| 2 | MG996R 180° PWM（夾爪開合） |
| 3 | MG996R 180° PWM（承物盒擋板） |
| 4 | r 齒條伸出限位開關 |
| 5 | r 齒條縮回限位開關 |
| 6~10, 20, 21 | 備用 |

## ESP32 ↔ ESP32-C3 ×3（ESP-NOW 通訊）

```
ESP32（主控板，USB 插電腦）
    │
    ├── ESP-NOW（無線點對點）──→ ESP32-C3 #1（腿部）
    ├── ESP-NOW（無線點對點）──→ ESP32-C3 #2（大圓盤 + z）
    └── ESP-NOW（無線點對點）──→ ESP32-C3 #3（Servo 控制）

主控板功能：                                    子控板功能：
  - 藍芽接收（手機遙控 App）                     #1 - 腿部步行馬達控制（BTS7960 ×2）
  - ESP-NOW 指令分發                             #2 - 大圓盤旋轉 + z 升降控制（BTS7960 #3/#4）+ 限位開關
  （不直接驅動任何馬達）                          #3 - Servo ×3（r 齒條 + θ + 夾爪開合）+ 限位開關
  （USB 插電腦獨立供電）
```

> **ESP-NOW 特點**：不需 Wi-Fi 路由器，點對點通訊，延遲低，適合即時控制。  
> 需在主控板程式中初始化 ESP-NOW 並註冊三個子控板的 MAC 位址。  
> ESP32 主控板插電腦 USB 供電，與機器人之間完全無線連接。

## 組裝流程

> 完整分步組裝 SOP 請見 → [電控組裝SOP.md](電控組裝SOP.md)

組裝順序摘要（**務必按順序執行**）：

1. 電池盒量測電壓（14~16.8V）
2. XL4015 校準至 5.0V（**空載校準，三用電表確認**）
3. LM2596 校準至 5.0V
4. BTS7960 ×4 電源接線（B+/B- 接電池）+ R_EN/L_EN 接 3.3V → 上電測試
5. LM2596 → ESP32-C3 ×3 供電 → 上電確認
6. C3 #1 → BTS7960 #1/#2 信號線 + 馬達 → Serial 測試
7. C3 #2 → BTS7960 #3/#4 信號線 + 馬達 + 限位開關 → Serial 測試
8. C3 #3 → XL4015 Servo 電源 + 信號線 + 限位開關 → Serial 測試
9. ESP32 主控 → ESP-NOW 三路通訊測試
10. BLE 藍芽連線測試

> ⚠ 每一步完成後都要**驗證**再進入下一步。切勿跳步驟！

## 限位開關安裝

### 接線方式

所有限位開關採用 **常開（NO）** 接法，搭配 `INPUT_PULLUP`：

```
ESP32-C3 GPIO ──── Limit Switch (NO 端子) ──── GND
                     │
              [C 共同端] ── GND
              [NO 常開端] ── GPIO
              [NC 常閉端] ── 不接
```

- **未觸發**：GPIO 被內部上拉電阻拉到 HIGH (3.3V)
- **觸發時**：開關閉合，GPIO 被拉到 LOW (GND) → 軟體偵測到後停止馬達

### 實體安裝要點

1. **r 齒條限位** ×2（C3 #3 GPIO 4, 5）：
   - 安裝在齒條軌道的**兩端盡頭**
   - 觸發桿朝向齒條運動方向
   - 齒條撞到觸發桿 → 開關觸發 → 360° Servo 停止
   - 預留 2-3mm 緩衝行程（開關觸發到物理盡頭之間）

2. **z 升降限位** ×2（C3 #2 GPIO 9, 10）：
   - 安裝在升降機構的**上下極限位置**
   - z 軸升到頂/降到底時觸發
   - 蝸桿馬達自鎖，停止後不會滑動

3. **大圓盤限位** ×2（C3 #2 GPIO 7, 8）— **可選**：
   - 如果大圓盤可 360° 自由旋轉，可省略
   - 如需限制旋轉角度，在圓盤邊緣安裝擋片

### 安裝固定方式

- 用 M3 螺絲將微動開關固定在 3D 列印支架或壓克力板上
- 觸發桿方向需與運動方向**垂直**（確保可靠觸發）
- 接線用杜邦線即可（電流 < 1mA）
- 線材沿機構走線，用束線帶固定，避免被運動部件夾住

## 共地匯流排設計

> 所有 GND 必須可靠連通。建議使用端子台集中管理。

```
GND 匯流排（端子台，至少 7 位）
  ├── 電池 GND
  ├── BTS7960 #1 GND
  ├── BTS7960 #2 GND
  ├── BTS7960 #3 GND
  ├── BTS7960 #4 GND
  ├── XL4015 GND
  ├── LM2596 GND
  └── C3 #1/#2/#3 GND（可從 LM2596 GND 延伸）

Servo GND 從 XL4015 GND 端延伸，也必須與匯流排連通。
```

> ⚠ 不要使用「菊花鏈」接法（A→B→C→D），改用「星形」接法（全部回到端子台），減少接觸電阻。

## 安全注意事項

1. 🔥 **禁止麵包板分電**：麵包板觸點僅額定 ~1A，不得用於 12V 電源分配（僅適合 3.3V/5V 信號原型）
2. 🔥 **禁止杜邦線作電源線**：杜邦線 28AWG 僅額定 1.4A，電源線必須使用 18-22AWG 矽膠線
3. **保險絲**：電池正極出口必須串聯 10A 保險絲，短路時保險絲熔斷保護線路
4. **端子台分電**：所有電源分配使用端子台，不得使用麵包板或任何臨時接法
5. **共地**：機器人上所有模組的 GND 都要連在一起（C3 ×3、BTS7960 ×4、XL4015、LM2596、Servo）
6. **ESP32 主控不需共地**：主控插電腦，透過 ESP-NOW 無線通訊，與機器人電源獨立
7. **勿反接**：馬達方向不對是正常的，改 BTS7960 M+/M- 接線即可，但電源 B+/B- 絕對不能反接
8. **先測後裝**：先在桌上測試所有接線，確認正常後再裝上底盤
9. **電池保護**：鋰電池不要過放（單顆低於 3.0V 就該充電），不用時拔掉電池接頭
10. **散熱**：BTS7960 效率高（>95%），幾乎不發熱
11. **ESP32-C3 電壓**：ESP32-C3 GPIO 為 3.3V 電平，BTS7960 原生支援 3.3V 邏輯；Servo 信號線可直接接（MG996R 接受 3.3V 信號）
12. **Servo 供電分離**：Servo 電源必須從 XL4015 取，不可從 LM2596 或 C3 取電，避免突波影響 MCU
13. **XL4015 校準**：首次使用 XL4015 時，先不接負載，通電後用三用電表量輸出，轉旋鈕調到 5.0V
14. **齒條限位**：r 齒條兩端必須裝限位開關，360° Servo 沒有位置回饋，靠限位開關防止過行程
15. **線材載流量**：電源線必須使用足夠粗的線材，杜邦線僅適用信號線（詳見 [電源預算.md](電源預算.md)）
16. **BTS7960 電源端子**：所有 B+ / B- 端子需鎖緊，鬆動會造成接觸不良或打火
