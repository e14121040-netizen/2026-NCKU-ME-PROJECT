# 取物機器人 — 接線圖

> 本文件列出取物機器人所有電路接線。  
> 已更新為 ESP32 + ESP32-C3 ×3 + ESP-NOW 分散式模組化架構。  
> ⚠ **最後更新：2026/05/05** — 馬達配置與供電架構全面更新。

## 系統供電架構

```
18650 鋰電池 × 4（四節電池盒，串聯 ≈ 14.8V~16.8V）
    │
    ├──→ L298N #1 (12V in)（腿部步行馬達供電，由 C3 #1 控制）
    │       ├── OUT A → JGB37-520 左腿（左側 4 足）
    │       └── OUT B → JGB37-520 右腿（右側 4 足）
    │
    ├──→ L298N #2 (12V in)（大圓盤 + z 升降馬達供電，由 C3 #2 控制）
    │       ├── OUT A → XD-25GA 370 夾爪底部大圓盤旋轉
    │       └── OUT B → JGY370 z 方向升降（12V 蝸桿自鎖）
    │
    ├──→ XL4015 降壓模組 → 5V【Servo 專用電源】
    │       ├── MG996R 360°（r 齒條伸縮）── 信號線接 C3 #3 GPIO
    │       ├── MG996R 180°（夾爪 θ 旋轉）── 信號線接 C3 #3 GPIO
    │       ├── MG996R 180°（夾爪開合）── 信號線接 C3 #3 GPIO
    │       └── ⚡ 輸出端並聯 1000μF 電解電容 + 100nF 陶瓷電容
    │
    └──→ LM2596 降壓模組 → 5V【MCU 專用電源】
            ├── ESP32-C3 #1（腿部子控板）
            ├── ESP32-C3 #2（大圓盤 + z 子控板）
            └── ESP32-C3 #3（Servo 子控板）

ESP32 主控板 → USB 插電腦供電（獨立電源，透過 ESP-NOW 無線通訊）
```

> ⚠ **重要**：
> - Servo 電源（XL4015）與 MCU 電源（LM2596）**必須分開**，避免 Servo 突波造成 ESP32 重啟
> - Servo 的 V+（紅線）接 XL4015 5V 輸出，信號線（橘線）接 C3 #3 GPIO，GND（棕線）接共地
> - XL4015 首次使用需先用三用電表校準輸出至 **5.0V**，再接 Servo
> - 所有模組的 **GND 必須共地**（電池 GND = L298N GND = XL4015 GND = LM2596 GND = C3 GND）
> - ESP32 主控插電腦時不需與機器人共地（ESP-NOW 是無線通訊）

## 電流估算

### 12V 側（電池直供 L298N）

| 負載 | 正常電流 | 峰值電流（堵轉） |
|------|---------|-----------------|
| JGB37-520 × 2（腿部行走） | ~2.4A | ~10A |
| XD-25GA 370 × 1（大圓盤） | ~0.5A | ~2A |
| JGY370 × 1（z 升降） | ~0.5A | ~1.5~3A |
| **12V 總計** | **~3.4A** | **~15A（極端）** |

### 5V 側 — XL4015（Servo 專用，最大 5A）

| 負載 | 正常電流 | 峰值電流 |
|------|---------|---------|
| MG996R × 3（動作中） | ~1.5A | ~7.5A（3 顆同時堵轉） |

> ⚠ 避免 3 顆 Servo 同時堵轉。正常操作（1~2 顆同時動作）在 5A 額定內安全。

### 5V 側 — LM2596（MCU 專用，最大 3A）

| 負載 | 電流 |
|------|------|
| ESP32-C3 × 3 | ~0.3A |
| **MCU 總計** | **~0.3A** ✅ 綽綽有餘 |

## ESP32-C3 #1 ↔ L298N #1（腿部步行馬達）

> **注意**：GPIO 腳位依 ESP32-C3 Super Mini 實際可用 GPIO 分配。

```
ESP32-C3 #1            L298N #1
───────────            ───────
GPIO 0           ──→  IN1  ─┐
GPIO 1           ──→  IN2  ─┤── 馬達 A：JGB37-520（左側 4 足）
GPIO 3 (PWM)     ──→  ENA  ─┘

GPIO 4           ──→  IN3  ─┐
GPIO 5           ──→  IN4  ─┤── 馬達 B：JGB37-520（右側 4 足）
GPIO 6 (PWM)     ──→  ENB  ─┘

GND              ──→  GND   (共地)
```

> L298N #1 的 ENA/ENB **跳線帽必須拔除**，才能使用 PWM 調速。

## ESP32-C3 #2 ↔ L298N #2（大圓盤旋轉 + z 升降）

```
ESP32-C3 #2            L298N #2
───────────            ───────
GPIO 0           ──→  IN1  ─┐
GPIO 1           ──→  IN2  ─┤── 馬達 A：XD-25GA 370（夾爪底部大圓盤旋轉）
GPIO 3 (PWM)     ──→  ENA  ─┘

GPIO 4           ──→  IN3  ─┐
GPIO 5           ──→  IN4  ─┤── 馬達 B：JGY370（z 方向升降，12V 蝸桿自鎖）
GPIO 6 (PWM)     ──→  ENB  ─┘

GND              ──→  GND   (共地)
```

### 限位開關（ESP32-C3 #2）

```
GPIO 7  ──→ 大圓盤左極限 (Limit Switch, 常開 NO, 接 GND)
GPIO 8  ──→ 大圓盤右極限
GPIO 9  ──→ z 上升極限
GPIO 10 ──→ z 下降極限
```

> **接法**：GPIO ---- Limit Switch (NO) ---- GND，使用 `INPUT_PULLUP`  
> ⚠ 如果大圓盤不需要限位開關（可 360° 自由旋轉），可將 GPIO 7, 8 省下備用。

## ESP32-C3 #3 — Servo 控制（r 齒條 + θ 旋轉 + 夾爪開合）

```
ESP32-C3 #3            伺服馬達
───────────            ────────
GPIO 0 (PWM)     ──→  MG996R 360°（r 齒條伸縮）── 信號線
GPIO 1 (PWM)     ──→  MG996R 180°（夾爪 θ 旋轉）── 信號線
GPIO 2 (PWM)     ──→  MG996R 180°（夾爪開合）── 信號線

限位開關：
GPIO 4           ──→  r 齒條伸出極限 (NO, 接 GND)
GPIO 5           ──→  r 齒條縮回極限 (NO, 接 GND)

GND              ──→  共地
```

> **Servo 電源接線**：
> - V+（紅線）──→ XL4015 5V 輸出（**不是** C3 的 3.3V/5V pin）
> - GND（棕線）──→ 共地（XL4015 GND = C3 GND = 電池 GND）
> - 信號線（橘線）──→ C3 #3 對應 GPIO

> ⚠ **r 齒條限位開關**：齒條伸到底或縮到底時觸發，軟體端收到信號後立即停止 360° Servo，防止齒條過行程。

### C3 #3 GPIO 使用總結

| GPIO | 用途 |
|------|------|
| 0 | MG996R 360° PWM（r 齒條） |
| 1 | MG996R 180° PWM（θ 旋轉） |
| 2 | MG996R 180° PWM（夾爪開合） |
| 4 | r 齒條伸出限位開關 |
| 5 | r 齒條縮回限位開關 |
| 3, 6~10, 20, 21 | 備用 |

## ESP32 ↔ ESP32-C3 ×3（ESP-NOW 通訊）

```
ESP32（主控板，USB 插電腦）
    │
    ├── ESP-NOW（無線點對點）──→ ESP32-C3 #1（腿部）
    ├── ESP-NOW（無線點對點）──→ ESP32-C3 #2（大圓盤 + z）
    └── ESP-NOW（無線點對點）──→ ESP32-C3 #3（Servo 控制）

主控板功能：                                    子控板功能：
  - 藍芽接收（手機遙控 App）                     #1 - 腿部步行馬達控制（L298N #1）
  - ESP-NOW 指令分發                             #2 - 大圓盤旋轉 + z 升降控制（L298N #2）+ 限位開關
  （不直接驅動任何馬達）                          #3 - Servo ×3（r 齒條 + θ + 夾爪開合）+ 限位開關
  （USB 插電腦獨立供電）
```

> **ESP-NOW 特點**：不需 Wi-Fi 路由器，點對點通訊，延遲低，適合即時控制。  
> 需在主控板程式中初始化 ESP-NOW 並註冊三個子控板的 MAC 位址。  
> ESP32 主控板插電腦 USB 供電，與機器人之間完全無線連接。

## 安全注意事項

1. **共地**：機器人上所有模組的 GND 都要連在一起（C3 ×3、L298N ×2、XL4015、LM2596、Servo）
2. **ESP32 主控不需共地**：主控插電腦，透過 ESP-NOW 無線通訊，與機器人電源獨立
3. **勿反接**：馬達方向不對是正常的，改 IN1/IN2 接線即可，但電源絕對不能反接
4. **先測後裝**：先在桌上測試所有接線，確認正常後再裝上底盤
5. **電池保護**：鋰電池不要過放（單顆低於 3.0V 就該充電），不用時拔掉電池接頭
6. **散熱**：L298N 會發熱，2 塊 L298N 需確保有足夠散熱空間
7. **ESP32-C3 電壓**：ESP32-C3 GPIO 為 3.3V 電平，Servo 信號線可直接接（MG996R 接受 3.3V 信號）
8. **Servo 供電分離**：Servo 電源必須從 XL4015 取，不可從 LM2596 或 C3 取電，避免突波影響 MCU
9. **XL4015 校準**：首次使用 XL4015 時，先不接負載，通電後用三用電表量輸出，轉旋鈕調到 5.0V
10. **齒條限位**：r 齒條兩端必須裝限位開關，360° Servo 沒有位置回饋，靠限位開關防止過行程
