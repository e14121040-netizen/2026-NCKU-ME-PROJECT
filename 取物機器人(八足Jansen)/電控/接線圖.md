# 取物機器人 — 接線圖

> 本文件列出取物機器人所有電路接線。  
> 已更新為 ESP32 + ESP32-C3 ×3 + ESP-NOW 分散式模組化架構。

## 系統供電架構

```
18650 鋰電池 × 4（四節電池盒）
    │
    ├──→ L298N #1 12V 輸入（腿部步行馬達供電，由 C3 #1 控制）
    │
    ├──→ L298N #2 12V 輸入（手臂 r/θ 馬達供電，由 C3 #2 控制）
    │
    ├──→ L298N #3 12V 輸入（z 升降馬達供電，由 C3 #3 控制）
    │
    └──→ LM2596 降壓模組 → 5V 輸出
             ├──→ ESP32 主控板供電（Vin 或 5V pin）
             ├──→ ESP32-C3 #1 供電
             ├──→ ESP32-C3 #2 供電
             ├──→ ESP32-C3 #3 供電
             └──→ 伺服馬達供電（夾爪 + 承物台，由 C3 #3 GPIO PWM 驅動）
```

> ⚠ **重要**：伺服馬達的供電線（V+）接 5V 電源，控制信號線接 ESP32-C3 #3 的 GPIO。

## ESP32-C3 #1 ↔ L298N #1（腿部步行馬達）

> **注意**：GPIO 腳位依 ESP32-C3 Super Mini 實際可用 GPIO 分配。

```
ESP32-C3 #1            L298N #1
───────────            ───────
GPIO 0           ──→  IN1  ─┐
GPIO 1           ──→  IN2  ─┤── 馬達 A（左側 4 足）
GPIO 3 (PWM)     ──→  ENA  ─┘

GPIO 4           ──→  IN3  ─┐
GPIO 5           ──→  IN4  ─┤── 馬達 B（右側 4 足）
GPIO 6 (PWM)     ──→  ENB  ─┘

GND              ──→  GND   (共地)
```

## ESP32-C3 #2 ↔ L298N #2（手臂 r/θ 馬達）

> 此部分已在 `noah_夾爪控制測試.ino` 中實作。

```
ESP32-C3 #2            L298N #2
───────────            ───────
GPIO 0           ──→  IN1  ─┐
GPIO 1           ──→  IN2  ─┤── XD-25GA 370 手臂伸縮馬達 (r)
GPIO 3 (PWM)     ──→  ENA  ─┘

GPIO 4           ──→  IN3  ─┐
GPIO 5           ──→  IN4  ─┤── XD-25GA 370 手臂旋轉馬達 (θ)
GPIO 6 (PWM)     ──→  ENB  ─┘

GND              ──→  GND   (共地)
```

### 限位開關（ESP32-C3 #2）

```
GPIO 7  ──→ r 伸出極限 (Limit Switch, 常開 NO, 接 GND)
GPIO 8  ──→ r 縮回極限
GPIO 9  ──→ θ 左極限
GPIO 10 ──→ θ 右極限
```

> **接法**：GPIO ---- Limit Switch (NO) ---- GND，使用 `INPUT_PULLUP`

## ESP32-C3 #3 ↔ L298N #3 + 伺服馬達（z 升降 / 夾爪 / 承物台）

```
ESP32-C3 #3            L298N #3
───────────            ───────
GPIO 0           ──→  IN1  ─┐
GPIO 1           ──→  IN2  ─┤── z 方向升降馬達
GPIO 3 (PWM)     ──→  ENA  ─┘

GND              ──→  GND   (共地)

伺服馬達接線：
GPIO 4 (PWM)     ──→  夾爪伺服馬達（信號線）
GPIO 5 (PWM)     ──→  承物台伺服馬達（信號線）

限位開關：
GPIO 7           ──→  z 上升極限 (NO, 接 GND)
GPIO 8           ──→  z 下降極限 (NO, 接 GND)
```

> **伺服馬達接線**：信號線接 C3 GPIO，V+（紅線）接 5V 電源，GND（棕線）接共地。

## ESP32 ↔ ESP32-C3 ×3（ESP-NOW 通訊）

```
ESP32（主控板）── ESP-NOW（無線點對點）──→ ESP32-C3 #1（腿部）
              ── ESP-NOW（無線點對點）──→ ESP32-C3 #2（手臂 r/θ）
              ── ESP-NOW（無線點對點）──→ ESP32-C3 #3（z/夾爪）

主控板功能：                                    子控板功能：
  - 藍芽接收（手機遙控 App）                     #1 - 腿部步行馬達控制
  - ESP-NOW 指令分發                             #2 - 手臂 r/θ 馬達 + 限位開關
  （不直接驅動任何馬達）                          #3 - z 升降馬達 + 夾爪/承物台伺服
```

> **ESP-NOW 特點**：不需 Wi-Fi 路由器，點對點通訊，延遲低，適合即時控制。  
> 需在主控板程式中初始化 ESP-NOW 並註冊三個子控板的 MAC 位址。

## 安全注意事項

1. **共地**：所有模組的 GND 都要連在一起（ESP32、C3 ×3、L298N ×3、伺服馬達）
2. **勿反接**：馬達方向不對是正常的，改 IN1/IN2 接線即可，但電源絕對不能反接
3. **先測後裝**：先在桌上測試所有接線，確認正常後再裝上底盤
4. **電池保護**：鋰電池不要過放（單顆低於 3.0V 就該充電），不用時拔掉電池接頭
5. **散熱**：L298N 會發熱，3 塊 L298N 需確保有足夠散熱空間
6. **ESP32-C3 電壓**：ESP32-C3 GPIO 為 3.3V 電平，伺服馬達信號線可直接接
7. **伺服馬達供電**：伺服馬達電流需求較大，確保 5V 電源穩定充足
