# 取物機器人 — 接線圖

> 本文件列出取物機器人所有電路接線。  
> 已更新為 ESP32 + ESP32 C3 + ESP-NOW 模組化架構。

## 系統供電架構

```
18650 鋰電池 × 4（四節電池盒）
    │
    ├──→ L298N #1 12V 輸入（步行馬達供電）
    │
    ├──→ L298N #2 12V 輸入（手臂/夾爪馬達供電）
    │
    ├──→ LM2596 降壓模組 → 5V 輸出
    │        ├──→ ESP32 供電（Vin 或 5V pin）
    │        └──→ PCA9685 V+（伺服馬達供電）
    │
    └──→ ESP32 C3 供電（可透過 USB 或降壓模組）
```

> ⚠ **重要**：PCA9685 的 V+ 是伺服馬達專用電源，不要跟邏輯電源混用。

## 模組化架構概覽

```
                    ┌─────────────────┐
    遙控 App ←─BLE─┤    ESP32        ├─ ESP-NOW ──→ ESP32 C3
    (手機藍芽)      │   （主控板）      │              （子控板）
                    │                 │              ├ Z 方向控制
   L298N #1 ←GPIO─┤  馬達控制       │              └ 夾爪指令
  (步行馬達)  PWM──┤                 │
                    │                 │
   PCA9685 ←─I2C──┤  (SDA, SCL)    │
   (伺服馬達)       │                 │
                    │                 │
   Limit Switch ───┤  夾爪極限保護   │
                    │                 │
                    └─────────────────┘
```

## ESP32 ← → L298N #1（步行馬達）

> **注意**：具體 GPIO Pin 分配依實際接線確認，以下為建議配置。

```
ESP32                  L298N #1
─────                  ───────
GPIO [待定]       ──→  IN1  ─┐
GPIO [待定]       ──→  IN2  ─┤── 馬達 A（左側 4 足）
GPIO [待定] (PWM) ──→  ENA  ─┘

GPIO [待定]       ──→  IN3  ─┐
GPIO [待定]       ──→  IN4  ─┤── 馬達 B（右側 4 足）
GPIO [待定] (PWM) ──→  ENB  ─┘

GND               ──→  GND   (共地)
```

## ESP32 C3 ← → L298N #2（手臂/夾爪馬達）

```
ESP32 C3               L298N #2
────────               ───────
GPIO [待定]       ──→  IN1  ─┐
GPIO [待定]       ──→  IN2  ─┤── XD-25GA 370 手臂馬達
GPIO [待定] (PWM) ──→  ENA  ─┘

GPIO [待定]       ──→  IN3  ─┐
GPIO [待定]       ──→  IN4  ─┤── XD-25GA 370 夾爪馬達
GPIO [待定] (PWM) ──→  ENB  ─┘

GND               ──→  GND   (共地)
```

> **注意**：L298N 板上的 ENA/ENB 跳線帽要拔掉，才能用 PWM 調速。

## ESP32 ← → PCA9685（伺服馬達）

```
ESP32                  PCA9685
─────                  ───────
GPIO 21 (SDA)    ←→  SDA    (I2C 資料)
GPIO 22 (SCL)    ──→ SCL    (I2C 時脈)
3.3V             ──→ VCC    (邏輯電源)
GND              ──→ GND    (共地)

                       伺服電源
                V+  ←── LM2596 降壓模組 5V 輸出
                GND ←── 外接電源 GND
```

### 伺服馬達通道分配

| PCA9685 通道 | 伺服馬達 | 角度範圍 | 歸位角度 | 備註 |
|-------------|---------|---------|---------|------|
| CH 0 | 肩關節 (MG996R) | 30°~150° | 90° | 若已改用 370 減速馬達，則此通道停用 |
| CH 1 | 肘關節 (MG996R) | 30°~150° | 90° | 若已改用 370 減速馬達，則此通道停用 |
| CH 2 | 夾爪 (SG90) | 40°~110° | 40° (開) | 視夾爪設計是否保留小伺服 |
| CH 3 | 承物台 (SG90/MG90S) | 0°~60° | 0° (水平) | 傾斜倒出機構 |
| CH 4~5 | 預留 | — | — | 可擴充 |

## ESP32 ← → ESP32 C3（ESP-NOW 通訊）

```
ESP32（主控板）────── ESP-NOW（無線點對點）──────→ ESP32 C3（子控板）

主控板功能：                                    子控板功能：
  - 馬達控制（步行）                               - Z 方向控制
  - 遙控接收（藍芽 App）                           - 夾爪開合指令
  - 夾爪指令發送                                   
```

> **ESP-NOW 特點**：不需 Wi-Fi 路由器，點對點通訊，延遲低，適合即時控制。  
> 需在程式中初始化 ESP-NOW 並註冊對方的 MAC 位址。

## 安全注意事項

1. **共地**：所有模組的 GND 都要連在一起
2. **勿反接**：馬達方向不對是正常的，改 IN1/IN2 接線即可，但電源絕對不能反接
3. **先測後裝**：先在桌上測試所有接線，確認正常後再裝上底盤
4. **電池保護**：鋰電池不要過放（單顆低於 3.0V 就該充電），不用時拔掉電池接頭
5. **散熱**：L298N 會發熱，確保有散熱空間
6. **ESP32 電壓**：ESP32 GPIO 為 3.3V 電平，部分感測器需注意電平轉換
