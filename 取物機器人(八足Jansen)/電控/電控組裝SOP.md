# 取物機器人 — 電控組裝 SOP

> 本文件為電控系統的完整組裝與驗證流程。  
> 按照以下步驟依序執行，每步完成後進行驗證，確保安全與正確。  
> ⚠ **最後更新：2026/05/19** — 新增承物盒擋板 Servo 接線與測試。

---

> ### 🔥 事故教訓（2026/05/12）
>
> 使用**杜邦線 + 麵包板**分配電池電源至 BTS7960，通電後杜邦線立即燒毀。  
> **根因**：杜邦線 28AWG 額定僅 1.4A，麵包板觸點額定 ~1A；實際電流 3.4A+ 遠超載流量。  
>
> **教訓**：
> - ❌ **嚴禁使用麵包板分配 12V 電源**（麵包板僅適合 3.3V/5V 信號電路原型驗證）
> - ❌ **嚴禁使用杜邦線作為電源線**（僅適合信號線，≤1A）
> - ✅ 電源分配必須使用**端子台 (terminal block) + 18AWG 矽膠線**
> - ✅ 電池正極出口處必須串聯 **10A 保險絲**，防止短路時燒線

## 階段一：電源系統（Step 1-4）

### Step 1：電池盒接線 + 保險絲安裝

**操作**：
1. 四節 18650 裝入電池盒（注意正負極方向）
2. 電池盒正極（紅線）和負極（黑線）先**不要接任何東西**
3. 用三用電表量測電池盒輸出電壓
4. **在正極線上串聯保險絲座**：電池盒紅線 → 保險絲座 → 正極端子台（使用 18AWG 線）
5. 插入 **10A 保險絲**（或 15A，視需求而定）

**驗證**：
- [ ] 電壓讀數在 14.0V ~ 16.8V 之間
- [ ] 正負極標記清楚
- [ ] 保險絲座已串聯在正極線上
- [ ] 保險絲額定值正確（10A 或 15A）

> ⚠ 如果電壓 < 12V，表示有電池沒裝好或電量不足。
>
> 🔥 **嚴禁事項**：
> - ❌ 不得使用麵包板 (breadboard) 分配電源
> - ❌ 不得使用杜邦線 (28AWG) 作為電池到馬達驅動的電源線
> - ✅ 所有電源線必須使用 **18AWG 矽膠線**
> - ✅ 電源分配必須使用**端子台 (terminal block)**

---

### Step 2：降壓模組校準（XL4015）

**操作**：
1. 電池盒 → XL4015 **IN+/IN-**（用 18-20AWG 線）
2. XL4015 **OUT+/OUT-** 先不接任何負載
3. 接通電池盒電源
4. 用三用電表量 XL4015 OUT+ 和 OUT- 之間的電壓
5. 用小螺絲起子**慢慢轉動**電位器旋鈕，調到 **5.0V**（±0.1V）
6. 確認後斷電

**驗證**：
- [ ] XL4015 輸出穩定在 4.9V ~ 5.1V
- [ ] 輸出端焊上/接好 1000μF 電解電容（注意正負極！長腳正極）
- [ ] 並聯 100nF 陶瓷電容（無極性）

> ⚠ 電位器通常需要轉很多圈，耐心調整。逆時針通常是降壓。

---

### Step 3：降壓模組校準（LM2596）

**操作**：
1. 電池盒 → LM2596 **IN+/IN-**
2. 重複 Step 2 的校準流程
3. 調整輸出至 **5.0V**

**驗證**：
- [ ] LM2596 輸出穩定在 4.9V ~ 5.1V

---

### Step 4：馬達驅動電源接線（端子台分配）

**操作**：

> 🔥 **電源分配必須使用端子台，嚴禁麵包板！**
> 從電池盒出來的正極線（經保險絲後）接到正極端子台，負極線接到 GND 端子台。
> 再從端子台分別拉 18AWG 線到各 BTS7960。

**正極端子台分配**（電池正極 → 保險絲 → 正極端子台）：
1. 正極端子台 → BTS7960 #1 的 **B+**（18AWG 矽膠線）
2. 正極端子台 → BTS7960 #2 的 **B+**（18AWG 矽膠線）
3. 正極端子台 → BTS7960 #3 的 **B+**（18AWG 矽膠線）
4. 正極端子台 → BTS7960 #4 的 **B+**（18AWG 矽膠線）
5. 正極端子台 → XL4015 IN+（20AWG）
6. 正極端子台 → LM2596 IN+（22AWG）

**GND 端子台分配**（電池負極 → GND 端子台）：
7. GND 端子台 → BTS7960 #1 的 **B-**（18AWG 矽膠線）
8. GND 端子台 → BTS7960 #2 的 **B-**（18AWG 矽膠線）
9. GND 端子台 → BTS7960 #3 的 **B-**（18AWG 矽膠線）
10. GND 端子台 → BTS7960 #4 的 **B-**（18AWG 矽膠線）
11. GND 端子台 → XL4015 IN-（20AWG）
12. GND 端子台 → LM2596 IN-（22AWG）

**Enable 接線**：
13. BTS7960 #1/#2/#3/#4 **R_EN** 和 **L_EN** → 接 **3.3V**（從 C3 的 3.3V pin 取，或用跳線拉）
14. BTS7960 #1/#2/#3/#4 **GND** → GND 端子台

**通電前檢查**：
- [ ] 用三用電表通斷檔確認：正極端子台與 GND 端子台之間**不短路**
- [ ] 所有端子台螺絲已鎖緊

**驗證**（通電後）：
- [ ] 保險絲未熔斷
- [ ] BTS7960 #1/#2/#3/#4 通電無異常（模組上無指示燈，但不應冒煙或發燙）
- [ ] 用三用電表確認 BTS7960 的 VCC pin 有 ~3.3V（已接 Enable）

> ⚠ BTS7960 沒有板載 LED，通電後確認無異味即可。B+/B- **絕對不能反接**！

> 完成 Step 1-4 後斷電，進入階段二。

## 階段二：MCU 供電與基礎驗證（Step 5-6）

### Step 5：ESP32-C3 供電接線

**操作**：
1. LM2596 OUT+ → ESP32-C3 #1 的 **5V pin**（24AWG 或杜邦線）
2. LM2596 OUT- → ESP32-C3 #1 的 **GND pin**
3. 重複接 C3 #2、C3 #3
4. 用三用電表確認每塊 C3 的 5V/GND 之間電壓正確

**驗證**：
- [ ] 3 塊 C3 的 5V pin 量到 4.9~5.1V
- [ ] 所有 GND 已連通（用三用電表通斷檔測量任意兩個 GND 點）

---

### Step 6：MCU 上電測試

**操作**：
1. 先用 USB 線將 C3 #1 接電腦（暫時用 USB 供電）
2. 上傳 `00_macaddress` 程式
3. 打開 Serial Monitor (115200)，記錄 MAC 地址
4. 對 C3 #2、C3 #3 重複此步驟
5. 將 3 個 MAC 填入 `01_MainController.ino` 的對應欄位

**驗證**：
- [ ] 3 塊 C3 都能正常輸出 MAC 地址
- [ ] 已記錄 MAC 地址到 MainController 原始碼

```
C3 #1 (Leg):        __:__:__:__:__:__
C3 #2 (TurntableZ): __:__:__:__:__:__
C3 #3 (ServoClaw):  __:__:__:__:__:__
```

## 階段三：子控板接線與獨立測試（Step 7-9）

### Step 7：C3 #1 腿部接線（BTS7960 ×2）

**接線**（參考 [接線圖.md](接線圖.md)）：
```
【BTS7960 #1 — 左腿馬達】
C3 #1 GPIO 0 → BTS7960 #1 RPWM（正轉 PWM）
C3 #1 GPIO 1 → BTS7960 #1 LPWM（反轉 PWM）
BTS7960 #1 R_EN → 3.3V（常開）
BTS7960 #1 L_EN → 3.3V（常開）

【BTS7960 #2 — 右腿馬達】
C3 #1 GPIO 3 → BTS7960 #2 RPWM（正轉 PWM）
C3 #1 GPIO 4 → BTS7960 #2 LPWM（反轉 PWM）
BTS7960 #2 R_EN → 3.3V（常開）
BTS7960 #2 L_EN → 3.3V（常開）

C3 #1 GND    → BTS7960 #1/#2 GND（共地）
```

**馬達接線**：
```
BTS7960 #1 M+ / M- → JGB37-520 左腿馬達
BTS7960 #2 M+ / M- → JGB37-520 右腿馬達
```

**測試**：
1. 上傳 `02_LegController.ino` 至 C3 #1
2. 打開 Serial Monitor
3. 輸入 `f` → 兩馬達應正轉（前進）
4. 輸入 `b` → 兩馬達應反轉（後退）
5. 輸入 `l` → 左反右正（原地左旋）
6. 輸入 `0` → 全部停止
7. 輸入 `?` → 查看狀態

**驗證**：
- [ ] 前進時兩馬達同向旋轉
- [ ] 方向正確（如果反了，交換 BTS7960 M+/M- 的兩條馬達線）
- [ ] PWM 調速正常（`+`/`-` 可改變速度）
- [ ] 停止指令有效
- [ ] BTS7960 模組溫度正常（幾乎不發熱）

---

### Step 8：C3 #2 大圓盤 + z 接線

**接線**（參考 [接線圖.md](接線圖.md)）：
```
【BTS7960 #3 — 大圓盤馬達】
C3 #2 GPIO 0 → BTS7960 #3 RPWM（正轉 PWM）
C3 #2 GPIO 1 → BTS7960 #3 LPWM（反轉 PWM）
BTS7960 #3 R_EN → 3.3V（常開）
BTS7960 #3 L_EN → 3.3V（常開）

【BTS7960 #4 — z 升降】
C3 #2 GPIO 3 → BTS7960 #4 RPWM（上升 PWM）
C3 #2 GPIO 4 → BTS7960 #4 LPWM（下降 PWM）
BTS7960 #4 R_EN → 3.3V（常開）
BTS7960 #4 L_EN → 3.3V（常開）

C3 #2 GND    → BTS7960 #3 / #4 GND（共地）
```

**限位開關接線**：
```
C3 #2 GPIO 7  → 大圓盤左極限 NO → GND
C3 #2 GPIO 8  → 大圓盤右極限 NO → GND
C3 #2 GPIO 9  → z 上升極限 NO → GND
C3 #2 GPIO 10 → z 下降極限 NO → GND
```

**測試**：
1. 上傳 `03_TurntableZController.ino` 至 C3 #2
2. Serial 輸入 `a` → 大圓盤左轉
3. Serial 輸入 `u` → z 上升
4. Serial 輸入 `?` → 查看限位開關狀態
5. 手動按壓限位開關 → 確認顯示 `TRIGGERED`
6. 確認限位觸發時馬達自動停止

**驗證**：
- [ ] 大圓盤左/右轉正常（BTS7960 #3 驅動）
- [ ] z 升降正常（BTS7960 #4 驅動）
- [ ] 4 個限位開關都能正確觸發
- [ ] 限位觸發時馬達立即停止
- [ ] 超時保護有效（持續運轉 5 秒後自動停止）

---

### Step 9：C3 #3 Servo 接線

**Servo 電源接線**（注意：從 XL4015 取電，不是從 C3）：
```
XL4015 5V OUT → MG996R ×4 的 V+（紅線）
XL4015 GND   → MG996R ×4 的 GND（棕線）── 同時接 C3 #3 GND
```

**Servo 信號線**：
```
C3 #3 GPIO 0 → MG996R 360°（r 齒條）── 信號線（橘）
C3 #3 GPIO 1 → MG996R 180°（θ 旋轉）── 信號線（橘）
C3 #3 GPIO 2 → MG996R 180°（夾爪開合）── 信號線（橘）
C3 #3 GPIO 3 → MG996R 180°（承物盒擋板）── 信號線（橘）
```

**限位開關**：
```
C3 #3 GPIO 4 → r 齒條伸出極限 NO → GND
C3 #3 GPIO 5 → r 齒條縮回極限 NO → GND
```

**測試**：
1. 上傳 `04_ServoClawController.ino` 至 C3 #3
2. Serial 輸入 `w` → 360° Servo 正轉（r 伸出）
3. Serial 輸入 `s` → 360° Servo 反轉（r 縮回）
4. Serial 輸入 `0` → 360° 停轉
5. Serial 輸入 `i` → θ 旋轉正方向（角度 +15°）
6. Serial 輸入 `o` → 夾爪張開
7. Serial 輸入 `p` → 夾爪閉合
8. Serial 輸入 `h` → 歸位
9. Serial 輸入 `?` → 查看所有狀態

**驗證**：
- [ ] 360° Servo 正反轉正常，`0` 可停止
- [ ] 180° θ Servo 步進旋轉正常
- [ ] 180° 夾爪開合正常
- [ ] 180° 承物盒擋板開合正常（`g` 開擋板 / `n` 關擋板）
- [ ] 限位開關觸發時 360° Servo 停止
- [ ] 歸位功能正常（r 縮回 + 夾爪張開 + θ 居中 + 擋板關閉）

> ⚠ 如果 360° Servo 發 `write(90)` 仍然微轉，是零點偏移。修改 `R_STOP` 常數（±2~5）。

## 階段四：ESP-NOW 通訊整合（Step 10-11）

### Step 10：主控板 ESP-NOW 配對

**操作**：
1. 確認 3 個 MAC 已填入 `01_MainController.ino`
2. 上傳 `01_MainController.ino` 至 ESP32 主控板（USB 接電腦）
3. 打開 Serial Monitor
4. 確認輸出：`Peer added: C3#1 Leg` / `C3#2 TurntableZ` / `C3#3 ServoClaw`
5. Serial 輸入 `f` → 確認 `-> Leg CMD:1 SPD:200`
6. 觀察 C3 #1 的 Serial Monitor 是否收到指令
7. 逐一測試所有指令

**驗證**：
- [ ] ESP-NOW 三路 Peer 全部成功加入
- [ ] 腿部指令 `f/b/l/r/q/e/0` 正確轉發到 C3 #1（l/r/q/e 皆為原地旋轉）
- [ ] 大圓盤+z 指令 `a/d/u/j` 正確轉發到 C3 #2
- [ ] Servo 指令 `w/s/i/k/o/p/h` 正確轉發到 C3 #3
- [ ] 全停 `0` 同時發送三路

## 階段五：全系統驗證（Step 12）

### Step 12：聯調測試

**操作**：
1. 同時操作步行 + 手臂（確認不互相干擾）
2. 連續操作 5 分鐘，觀察穩定性
3. 量測電池電壓變化
4. 觸摸 BTS7960 散熱片，確認溫度合理（應 < 40°C）

**驗證**：
- [ ] 步行 + 手臂可同時操作
- [ ] ESP-NOW 延遲 < 0.5 秒
- [ ] 無突然斷電或重啟
- [ ] BTS7960 溫度正常（幾乎不發熱，應 < 40°C）（#1/#2/#3 所有 BTS7960）
- [ ] BTS7960 溫度正常（應 < 40°C）
- [ ] XL4015 溫度 < 70°C
- [ ] 5 分鐘後電池電壓 > 13V

## 線路整理建議

1. **標記每條線**：用標籤紙標記「C3#1-RPWM」「電池+」等
2. **分色管理**：紅=電源正、黑=GND、其他=信號
3. **束線帶固定**：每 10cm 束一次，避免鬆散纏繞
4. **應力釋放**：線材與 PCB 接點處預留彎曲餘量
5. **熱源管理**：BTS7960 幾乎不發熱，降壓模組附近不要堆疊線材
6. **共地匯流排**：使用端子台集中 GND 連接，而非菊花鏈

- [ ] 正極端子台與 GND 端子台之間**不短路**（三用電表通斷測試）
- [ ] 所有 GND 共地連通（三用電表通斷測試）
- [ ] XL4015 輸出 5.0V ± 0.1V
- [ ] LM2596 輸出 5.0V ± 0.1V
- [ ] BTS7960 #1/#2/#3/#4 B+/B- 接線正確（勿反接）
- [ ] BTS7960 #1/#2/#3/#4 R_EN/L_EN 已接 3.3V
- [ ] Servo V+ 接 XL4015（不是 C3 的 pin）
- [ ] 所有端子台螺絲已鎖緊
- [ ] 無裸露線頭可能短路
- [ ] 電池盒開關在 OFF（準備好再上電）
