# 取物機器人 — 電控組裝 SOP

> 本文件為電控系統的完整組裝與驗證流程。  
> 按照以下步驟依序執行，每步完成後進行驗證，確保安全與正確。  
> ⚠ **最後更新：2026/06/02** — 腿部改為獨立 4S 電池組，腿部馬達更新為 JGB37-555 DC 12V 66rpm。

---

> ### 🔥 事故教訓（2026/05/12）
>
> 使用**杜邦線 + 麵包板**分配電池電源至 BTS7960，通電後杜邦線立即燒毀。  
> **根因**：杜邦線 28AWG 額定僅 1.4A，麵包板觸點額定 ~1A；實際電流 3.4A+ 遠超載流量。腿部改用 JGB37-555 後，腿部電流峰值更高。
>
> **教訓**：
> - ❌ **嚴禁使用麵包板分配 12V 電源**（麵包板僅適合 3.3V/5V 信號電路原型驗證）
> - ❌ **嚴禁使用杜邦線作為電源線**（僅適合信號線，≤1A）
> - ✅ 電源分配必須使用**端子台 (terminal block) + 足夠線徑的矽膠線**；腿部電池主幹建議 16AWG，BTS7960 分支建議 18AWG
> - ✅ 腿部電池正極出口處必須串聯 **15A 保險絲**；其他機構電池正極出口處必須串聯 **10A 保險絲**

## 階段一：電源系統（Step 1-4）

### Step 1：兩組 4S 電池盒接線 + 保險絲安裝

**操作**：
1. 準備兩組四節 18650 電池盒，標記為「腿部 4S」與「其他機構 4S」。
2. 每組電池盒正極（紅線）和負極（黑線）先**不要接任何東西**，確認各自 4S BMS 已按模組標示接好 B-/B1/B2/B3/B+。
3. 用三用電表分別量測兩組電池盒輸出電壓。
4. **在腿部 4S 正極線上串聯 15A 保險絲座**：腿部電池盒紅線 → 保險絲座 → 腿部正極端子台（主幹使用 16AWG 線）。
5. **在其他機構 4S 正極線上串聯 10A 保險絲座**：其他機構電池盒紅線 → 保險絲座 → 其他機構正極端子台（使用 18AWG 線）。

**驗證**：
- [ ] 兩組電壓讀數都在 14.0V ~ 16.8V 之間
- [ ] 兩組 4S BMS 接線完成且沒有發熱、異味
- [ ] 兩組正負極標記清楚，正極沒有互接
- [ ] 兩組保險絲座已串聯在各自正極線上
- [ ] 腿部保險絲為 15A，其他機構保險絲為 10A

> ⚠ 如果任一組電壓 < 12V，表示有電池沒裝好或電量不足。
>
> 🔥 **嚴禁事項**：
> - ❌ 不得使用麵包板 (breadboard) 分配電源
> - ❌ 不得使用杜邦線 (28AWG) 作為電池到馬達驅動的電源線
> - ✅ 腿部電池主幹必須使用 **16AWG 矽膠線**；BTS7960 分支電源線使用 **18AWG 矽膠線**
> - ✅ 電源分配必須使用**端子台 (terminal block)**

---

### Step 2：降壓模組校準（XL4015）

**操作**：
1. 其他機構 4S 電池盒 → XL4015 **IN+/IN-**（用 18-20AWG 線）
2. XL4015 **OUT+/OUT-** 先不接任何負載
3. 接通電池盒電源
4. 用三用電表量 XL4015 OUT+ 和 OUT- 之間的電壓
5. 用小螺絲起子**慢慢轉動**電位器旋鈕，調到 **5.0V**（±0.1V）
6. 確認後斷電

**驗證**：
- [ ] XL4015 輸出穩定在 4.9V ~ 5.1V
- [ ] 輸出端焊上/接好 1000μF 電解電容（注意正負極！長腳正極）
- [ ] 並聯 100nF 陶瓷電容（無極性）

> ⚠ 電位器通常需要轉很多圈，耐心調整。逆時針通常是降壓。

> ⚠ **獨立 Servo 電池判斷**：
> - 若想讓 XL4015 單獨接 2S 18650（兩顆鋰電池串聯），不建議：2S 18650 滿電 8.4V、標稱 7.4V，放電後低於 XL4015 常見 8V 最低輸入規格。
> - 兩顆 AA/AAA NiMH 充電電池只有約 2.4~2.8V，不能接 XL4015 做 5V Servo 電源。
> - 若一定要 Servo 獨立供電，建議改用 3S 18650 → XL4015，或 2S 18650 → 支援 6~8.4V 輸入的 5V 5A buck-boost / UBEC。
> - Servo 電池即使獨立，XL4015 OUT-、Servo GND、C3 #3 GND 仍必須共地。

---

### Step 3：降壓模組校準（LM2596 ×2）

**操作**：
1. 腿部 4S 電池盒 → LM2596-Leg **IN+/IN-**。
2. 其他機構 4S 電池盒 → LM2596-Other **IN+/IN-**。
3. 兩顆 LM2596 都重複 Step 2 的校準流程。
4. 兩顆 LM2596 輸出都調整至 **5.0V**。

**驗證**：
- [ ] LM2596-Leg 輸出穩定在 4.9V ~ 5.1V
- [ ] LM2596-Other 輸出穩定在 4.9V ~ 5.1V

---

### Step 4：馬達驅動電源接線（端子台分配）

**操作**：

> 🔥 **電源分配必須使用端子台，嚴禁麵包板！**
> 兩組電源分開配線。腿部電池只供 BTS7960 #1/#2 與 LM2596-Leg；其他機構電池只供 BTS7960 #3/#4、XL4015 與 LM2596-Other。

**腿部正極端子台分配**（腿部電池正極 → 15A 保險絲 → 腿部正極端子台）：
1. 腿部正極端子台 → BTS7960 #1 的 **B+**（18AWG 矽膠線）
2. 腿部正極端子台 → BTS7960 #2 的 **B+**（18AWG 矽膠線）
3. 腿部正極端子台 → LM2596-Leg IN+（22AWG）

**腿部 GND 端子台分配**：
4. 腿部 GND 端子台 → BTS7960 #1 的 **B-**（18AWG 矽膠線）
5. 腿部 GND 端子台 → BTS7960 #2 的 **B-**（18AWG 矽膠線）
6. 腿部 GND 端子台 → LM2596-Leg IN-（22AWG）

**其他機構正極端子台分配**（其他機構電池正極 → 10A 保險絲 → 其他機構正極端子台）：
7. 其他機構正極端子台 → BTS7960 #3 的 **B+**（18AWG 矽膠線）
8. 其他機構正極端子台 → BTS7960 #4 的 **B+**（18AWG 矽膠線）
9. 其他機構正極端子台 → XL4015 IN+（20AWG）
10. 其他機構正極端子台 → LM2596-Other IN+（22AWG）

**其他機構 GND 端子台分配**：
11. 其他機構 GND 端子台 → BTS7960 #3 的 **B-**（18AWG 矽膠線）
12. 其他機構 GND 端子台 → BTS7960 #4 的 **B-**（18AWG 矽膠線）
13. 其他機構 GND 端子台 → XL4015 IN-（20AWG）
14. 其他機構 GND 端子台 → LM2596-Other IN-（22AWG）

**Logic / Enable 接線**：
15. BTS7960 #1/#2/#3/#4 **VCC** → 接對應 C3 的 **3.3V**
16. BTS7960 #1/#2/#3/#4 **R_EN** 和 **L_EN** → 接 **3.3V**（從對應 C3 的 3.3V pin 取，或用跳線拉）
17. BTS7960 #1/#2 **GND** → 腿部 GND 端子台；BTS7960 #3/#4 **GND** → 其他機構 GND 端子台

**通電前檢查**：
- [ ] 用三用電表通斷檔確認：各組正極端子台與各自 GND 端子台之間**不短路**
- [ ] 腿部正極端子台與其他機構正極端子台之間沒有相接
- [ ] 所有端子台螺絲已鎖緊

**驗證**（通電後）：
- [ ] 保險絲未熔斷
- [ ] BTS7960 #1/#2/#3/#4 通電無異常（模組上無指示燈，但不應冒煙或發燙）
- [ ] 用三用電表確認 BTS7960 的 VCC pin 有 ~3.3V
- [ ] 用三用電表確認 BTS7960 的 R_EN/L_EN pin 有 ~3.3V

> ⚠ BTS7960 沒有板載 LED，通電後確認無異味即可。B+/B- **絕對不能反接**！

> 完成 Step 1-4 後斷電，進入階段二。

## 階段二：MCU 供電與基礎驗證（Step 5-6）

### Step 5：ESP32-C3 供電接線

**操作**：
1. LM2596-Leg OUT+ → ESP32-C3 #1 的 **5V pin**（24AWG 或杜邦線）
2. LM2596-Leg OUT- → ESP32-C3 #1 的 **GND pin**
3. LM2596-Other OUT+ → ESP32-C3 #2/#3 的 **5V pin**
4. LM2596-Other OUT- → ESP32-C3 #2/#3 的 **GND pin**
5. 用三用電表確認每塊 C3 的 5V/GND 之間電壓正確

**驗證**：
- [ ] 3 塊 C3 的 5V pin 量到 4.9~5.1V
- [ ] 腿部組內 GND 已連通；其他機構組內 GND 已連通
- [ ] 腿部組與其他機構組正極沒有互接；正式架構下兩組 GND 不跨組連接

## 階段三：子控板接線與獨立測試（Step 7-9）

### Step 7：C3 #1 腿部接線（BTS7960 ×2）

**接線**（參考 [接線圖.md](接線圖.md)）：
```
【BTS7960 #1 — 左腿馬達】
C3 #1 GPIO 0 → BTS7960 #1 RPWM（正轉 PWM）
C3 #1 GPIO 1 → BTS7960 #1 LPWM（反轉 PWM）
BTS7960 #1 R_EN → 3.3V（常開）
BTS7960 #1 L_EN → 3.3V（常開）

【BTS7960 #2 — 右腿馬達】
C3 #1 GPIO 3 → BTS7960 #2 RPWM（正轉 PWM）
C3 #1 GPIO 4 → BTS7960 #2 LPWM（反轉 PWM）
BTS7960 #2 R_EN → 3.3V（常開）
BTS7960 #2 L_EN → 3.3V（常開）

C3 #1 GND    → BTS7960 #1/#2 GND（共地）
```

**馬達接線**：
```
BTS7960 #1 M+ / M- → JGB37-555 DC 12V 66rpm 左腿馬達
BTS7960 #2 M+ / M- → JGB37-555 DC 12V 66rpm 右腿馬達
```

**測試**：
1. 上傳 `02_LegController.ino` 至 C3 #1
2. 打開 Serial Monitor
3. 輸入 `f` → 兩馬達應正轉（前進）
4. 輸入 `b` → 兩馬達應反轉（後退）
5. 輸入 `l` → 左反右正（原地左旋）
6. 輸入 `0` → 全部停止
7. 輸入 `?` → 查看狀態

**驗證**：
- [ ] 前進時兩馬達同向旋轉
- [ ] 方向正確（如果反了，交換 BTS7960 M+/M- 的兩條馬達線）
- [ ] PWM 調速正常（`+`/`-` 可改變速度）
- [ ] 停止指令有效
- [ ] BTS7960 模組溫度正常
- [ ] 腿部 JGB37-555 以 duty 120~150 起測，馬達溫度沒有快速上升

---

### Step 8：C3 #2 RotatingArm 接線

**接線**（參考 [接線圖.md](接線圖.md)）：
```
【旋轉端 Servo ×3】
C3 #2 GPIO 0 → MG996R 360°（r 齒條）信號線
C3 #2 GPIO 1 → MG996R 180°（θ 旋轉）信號線
C3 #2 GPIO 5 → MG996R 180°（夾爪開合）信號線

【BTS7960 #4 — z 升降】
C3 #2 GPIO 3 → BTS7960 #4 RPWM（上升 PWM）
C3 #2 GPIO 4 → BTS7960 #4 LPWM（下降 PWM）
BTS7960 #4 R_EN → 3.3V（常開）
BTS7960 #4 L_EN → 3.3V（常開）

C3 #2 GND    → XL4015 / BTS7960 #4 / 其他機構 GND（共地）
```

> C3 #2 與上方 Servo ×3、BTS7960 #4、z 馬達一起放旋轉端。跨旋轉中心的供電線要預留鬆弛線圈。

**測試**：
1. 上傳 `03_RotatingArmController.ino` 至 C3 #2
2. Serial 輸入 `w` / `s` / `x` → r 齒條伸縮與停止
3. Serial 輸入 `i` / `k` → θ 旋轉
4. Serial 輸入 `o` / `p` → 夾爪開合
5. Serial 輸入 `u` / `j` → z 升降
4. Serial 輸入 `?` → 查看狀態

**驗證**：
- [ ] r 齒條、θ、夾爪均正常
- [ ] z 升降正常（BTS7960 #4 驅動）
- [ ] 超時保護有效（持續運轉 5 秒後自動停止）
- [ ] 線束走旋轉中心且有鬆弛線圈

---

### Step 9：C3 #3 FixedStage 接線

**Gate Servo 電源接線**（注意：從 XL4015 取電，不是從 C3）：
```
XL4015 5V OUT → Gate servo V+（紅線）
XL4015 GND   → Gate servo GND（棕線）── 同時接 C3 #3 GND
```

若 Servo 採獨立電池供電，仍要保持：
```
Servo 電池 / XL4015 OUT- / Gate servo GND / C3 #3 GND → 共地
```

**固定端 spin 與 Gate 信號線**：
```
C3 #3 GPIO 0 → BTS7960 #3 RPWM（固定端 spin left）
C3 #3 GPIO 1 → BTS7960 #3 LPWM（固定端 spin right）
C3 #3 GPIO 5 → Gate servo 信號線（橘）
```



**測試**：
1. 上傳 `04_FixedStageController.ino` 至 C3 #3
2. Serial 輸入 `a` → 固定端 spin left
3. Serial 輸入 `d` → 固定端 spin right
4. Serial 輸入 `g` → Gate open
5. Serial 輸入 `n` → Gate close
6. Serial 輸入 `0` → 固定端全部停止
9. Serial 輸入 `?` → 查看所有狀態

**驗證**：
- [ ] 固定端 spin 左右轉正常，`0` 可停止
- [ ] Gate 開合正常（`g` 開 / `n` 關）
- [ ] Gate 定時動作完成後會自動停止 PWM
- [ ] spin 超時保護有效（持續運轉 5 秒後自動停止）

> ⚠ C3 #3 不控制上方夾爪與 z，這些線不可和固定端 Gate / spin 綁成同一束跨旋轉關節。

## 階段四：ESP-NOW 通訊整合（Step 10-11）

### Step 10：主控板 ESP-NOW 配對

**操作**：
1. 確認 3 個 MAC 已填入 `01_MainController.ino`
2. 上傳 `01_MainController.ino` 至 ESP32 主控板（USB 接電腦）；Arduino IDE 的 `Partition Scheme` 選 `Huge APP`，CLI 使用 `esp32:esp32:esp32:PartitionScheme=huge_app`
3. 打開 Serial Monitor
4. 確認輸出：`Peer added: C3#1 Leg` / `C3#2 RotatingArm` / `C3#3 FixedStage`
5. Serial 輸入 `f` → 確認 `-> Leg CMD:1 SPD:150`
6. 觀察 C3 #1 的 Serial Monitor 是否收到指令
7. 逐一測試所有指令

**驗證**：
- [ ] ESP-NOW 三路 Peer 全部成功加入
- [ ] 腿部指令 `f/b/l/r/q/e/0` 正確轉發到 C3 #1（l/r/q/e 皆為原地旋轉）
- [ ] RotatingArm 指令 `w/s/x/i/k/o/p/u/j/h` 正確轉發到 C3 #2
- [ ] FixedStage 指令 `a/d/g/n` 正確轉發到 C3 #3
- [ ] 全停 `0` 同時發送三路

---

### Step 11：BLE 藍芽測試

**操作**：
1. 手機安裝 **BLE Controller – Arduino ESP32**
2. 搜尋藍芽裝置 `ESP32_MainController`
3. 建立自訂按鈕頁，至少放入 `FORWARD`、`LEGSTOP`、`TL`、`TZSTOP`、`EXTEND`、`SERVOSTOP`、`STOP`
4. 逐一測試分路停止與全域急停
5. 確認斷線時自動急停

**驗證**：
- [ ] BLE 連線穩定
- [ ] 手機發送指令，三路子控板正確回應
- [ ] `LEGSTOP` / `TZSTOP` / `SERVOSTOP` 只停止對應子系統
- [ ] BLE 斷線後所有馬達自動停止

- [ ] BTS7960 溫度正常（應 < 40°C）

## 線路整理建議

1. **標記每條線**：用標籤紙標記「C3#1-RPWM」「電池+」等
2. **分色管理**：紅=電源正、黑=GND、其他=信號
3. **束線帶固定**：每 10cm 束一次，避免鬆散纏繞
4. **應力釋放**：線材與 PCB 接點處預留彎曲餘量
5. **熱源管理**：BTS7960 幾乎不發熱，降壓模組附近不要堆疊線材
6. **共地匯流排**：使用端子台集中 GND 連接，而非菊花鏈
