# 取物機器人（八足 Theo Jansen）

> 本目錄包含八足 Theo Jansen 連桿取物機器人的全部資料。

## 系統架構

```
手機遙控 App（ESP32 內建藍芽）
    │
    ▼
ESP32（主控板，USB 插電腦供電）── 藍芽接收 + ESP-NOW 指令分發中心
    │
    ├── ESP-NOW ──→ ESP32-C3 #1（腿部子控板）
    │                 └── L298N #1 → JGB37-520 直流減速馬達 ×2
    │                                 （左右側八足步行，差速轉向）
    │
    ├── ESP-NOW ──→ ESP32-C3 #2（大圓盤 + z 子控板）
    │                 ├── L298N #2 Ch.A → XD-25GA 370（夾爪底部大圓盤旋轉）
    │                 ├── L298N #2 Ch.B → JGY370（z 方向升降，蝸桿自鎖）
    │                 └── 限位開關 → 大圓盤/z 極限保護
    │
    └── ESP-NOW ──→ ESP32-C3 #3（Servo 子控板）
                      ├── MG996R 360°（r 齒條伸縮，人眼判斷位置）
                      ├── MG996R 180°（夾爪 θ 旋轉）
                      ├── MG996R 180°（夾爪開合）
                      └── 限位開關 → r 齒條兩端保護

    電源（機器人上）：
    ├── 18650 鋰電池 × 4（四節串聯 ≈ 14.8V）
    ├── → L298N #1, #2 直供 12V
    ├── → XL4015 降壓 → 5V 5A【Servo 專用電源】
    └── → LM2596 降壓 → 5V 3A【MCU 專用電源】

    ESP32 主控板：USB 插電腦獨立供電（ESP-NOW 無線通訊）
```

透過 ESP-NOW 讓各個 ESP 控制板之間不需 Wi-Fi 即可做點對點通訊，在功能上設計模組化的系統。  
**主控板不直接驅動任何馬達**，僅負責藍芽指令接收與 ESP-NOW 指令分發，插電腦 USB 供電。

## 步行機構

- **類型**：Theo Jansen Linkage 八足（Spider Robot）
- **步態**：交替步態（Alternating Gait）— 同側每足相位差 90°，左右側錯開 180°
- **驅動**：左右各 1 顆直流減速馬達，差速轉向
- **控制**：由 ESP32-C3 #1（腿部子控板）透過 L298N 驅動
- **連桿參數**：Theo Jansen 11 Holy Numbers（縮放因子 0.7）

詳細連桿設計請見 → [TheoJansen連桿設計參考.md](機構設計/TheoJansen連桿設計參考.md)

## 夾取機構

### 設計概念

- **座標系統**：採用圓柱座標系（r, θ, z），降低設計複雜度同時保留足夠的自由度
- **傳動方式**：齒輪、齒條與馬達控制
- **設計目標**：重量減輕，採用角度夾爪

### 自由度配置

| 自由度 | 驅動元件 | 控制方式 | 控制板 |
|--------|---------|---------|--------|
| **r（伸縮）** | MG996R 360° + 齒條 | 人眼判斷，按住伸出/縮回 | C3 #3 |
| **θ（旋轉）** | MG996R 180° | PWM 角度控制 | C3 #3 |
| **z（升降）** | JGY370 蝸桿馬達 | L298N，蝸桿自鎖防滑 | C3 #2 |
| **大圓盤** | XD-25GA 370 | L298N，自鎖 | C3 #2 |
| **夾爪開合** | MG996R 180° | PWM 角度控制 | C3 #3 |

### 機構規格

- **夾爪類型**：齒輪齒條雙向平行夾爪 (Rack and Pinion) — 平行版 + 止滑墊
- **設計參考**：
  - ![夾爪設計圖1](夾爪/image.png)
  - ![夾爪設計圖2](夾爪/2026-03-14_003610.png)
  - ![夾爪設計圖3](夾爪/2026-03-14_003706.png)
  - ![夾爪設計圖4](夾爪/2026-03-14_003757.png)
- **機構設計**：
  - **夾爪本體**：使用 3D 列印製作夾爪板與溝槽板，齒輪採用壓克力雷射切割，齒條另外採購。
  - **r 方向伸縮**：MG996R 360° 連續旋轉舵機驅動齒條，搭配直線滑軌導引。
  - **大圓盤旋轉**：夾爪底部大圓盤由 XD-25GA 370 驅動，提供整體旋轉。
- **驅動設計**：
  - **r 伸縮**（C3 #3）：MG996R 360° 驅動齒條，操作員人眼判斷位置，按住按鈕伸出/縮回、放開停止。齒條兩端裝限位開關防護。
  - **θ 旋轉**（C3 #3）：MG996R 180° 標準伺服，精確角度控制。
  - **z 方向升降**（C3 #2）：JGY370 蝸桿減速馬達，由 L298N 控制正反轉。蝸桿自鎖，斷電不會下滑。
  - **大圓盤**（C3 #2）：XD-25GA 370 自鎖馬達，由 L298N 控制正反轉。
  - **夾爪開合**（C3 #3）：MG996R 180° 標準伺服，由 C3 GPIO PWM 直接驅動。
  - **安全保護機制**：r 齒條兩端 + z 升降兩端裝設限位開關（Limit Switch），觸發時 ESP32-C3 即時停止馬達，防止過行程。軟體輔以 Maximum Timeout（最大通電時間）作為保護。
- **貨架高度限制**：置物盤底部 156mm、邊框高 200mm → 手臂需伸入此高度。
- **夾取物限制**：最重零件為線性襯套 83.3g、最大外徑 32mm → 夾爪開口需大於 32mm，且馬達扭力需能支撐。

## 整體結構

- **分兩層設計**：
  - 上層：夾爪 + 機械手臂
  - 下層：承物台（堆高機）— 用於暫存取下的零件
- **承物台**：可傾斜式（一側絞鏈、一側伸縮桿），由 ESP32-C3 #3 的伺服馬達控制
- **目標**：希望一次處理兩筆訂單（取多個零件後一次傾倒）

## 快速開始

1. 閱讀 [BOM.md](BOM.md) 確認零件
2. 閱讀 [電控/接線圖.md](電控/接線圖.md) 完成接線
3. 閱讀 [esp32控制/README.md](../esp32控制/README.md) 了解程式架構與上傳流程
4. 上傳 ESP32 主控程式（`01_MainController`）
5. 上傳 ESP32-C3 子控板程式（`02_LegController` / `03_TurntableZController` / `04_ServoClawController`）
6. 設定 ESP32 藍芽遙控 App（參考 [App指令對照表](app_inventor/App指令對照表.md)）
7. 測試 ESP-NOW 三路通訊與步行、手臂、夾爪控制

| `q` | 左旋轉 | `e` | 右旋轉 |
| `0` | 全部停止 | | |
